## 4. 반죽 만들기

달걀·우유·밀가루·설탕을 누르거나 볼로 끌어 넣습니다. 현재 독립 재료 이미지가 없으므로 명확한 한글 카드와 ‘쏙!’ 텍스트 이동 효과를 사용합니다. 가짜 음식 아이콘을 만들지 않았습니다.

네 재료를 넣고 거품기를 고른 뒤 볼 안에서 원을 그립니다. 포인터의 타원 보정 각도 변화를 누적하여 약 4바퀴에서 완성합니다. 너무 큰 순간 이동과 중심 부근의 떨림은 계산하지 않습니다. 볼 본체는 고정하고 추출한 반죽 표면만 작게 회전합니다. 키보드는 조리 공간에 초점을 두고 Enter로 한 바퀴씩 젓습니다. 클릭만으로 자동 완성되지는 않습니다.

## 5. 컵에 담고 굽기

반죽 볼을 선택한 뒤 트레이를 누르거나 끌어 놓으면 분홍 컵에 반죽 질감이 표시됩니다. 정확한 작은 컵 테두리 안을 맞출 필요는 없습니다. 오븐 문을 열고 트레이를 안으로 끌어 넣은 뒤 문을 닫습니다. 약 3초 동안 조명과 김 효과, 같은 케이크 PNG의 점진적 크기 변화로 부푸는 느낌을 보여줍니다.

이는 **분홍 컵 한 개를 채우고 굽는 시험판**입니다. 다른 다섯 컵을 채우거나 독립적으로 꾸미지 않습니다. 굽기 전 컵/반죽 중간 이미지가 없으므로 실제 반죽에서 빵으로 변하는 사실적 애니메이션은 미구현입니다. 오븐은 음식이 아닌 분리된 SVG UI이며 공식 시안과 동일한 고품질 오븐 그림은 아닙니다. 선택 화면/초기화 확인창/숨겨진 탭에서는 굽기 시간이 진행되지 않습니다.

## 6. 크림과 장식

바닐라/딸기를 선택하고 짤주머니를 고릅니다. 컵케이크 위에서 손가락을 누르고 있거나 움직이면 약 2.4초에 걸쳐 크림이 자랍니다. 완성된 크림 PNG의 가로·세로 비율을 함께 유지하고, 바닥 중심을 케이크 위에 고정합니다. 굵은 선으로 크림을 새로 그리지 않습니다. 크림을 조금만 올리고 자유롭게 완성해도 됩니다.

스프링클을 고른 뒤 크림을 톡 누르거나 문지르면 작은 PNG 조각이 놓입니다. `id/kind/u/v/rotation/size`를 기록하고, 크림의 실제 알파 영역 안으로 제한합니다. 두 크림에 공통으로 존재하는 표면을 사용하므로 맛을 바꿔도 장식 위치가 유지됩니다. 렌더링에도 실제 크림 알파 마스크를 적용하여 가장자리 밖으로 튀어나가지 않습니다. ‘장식 빼기’를 고르고 가까운 조각을 누르면 제거하며, 되돌리기로 복구할 수 있습니다.

크림/장식 종류는 등록 데이터와 이미지 목록을 분리했습니다. 초콜릿 크림이나 과일을 추가할 때 전용 PNG와 메타데이터/표면 판정을 추가하면 됩니다. 현재 자유로운 3D 짤주머니 선 경로나 여러 층의 크림을 생성하는 기능은 아닙니다.

## 7. 저장과 PNG

전용 저장 키는 `kids-game-playground:v1:game:cooking-v2:cupcake:prototype:r1`입니다. 단계·재료·섞기·채움·굽기 경과·크림·짜기 진행·작은 장식·완성 상태·소리 설정을 자동 저장합니다. 이력은 최근 60개 조작이며, 긴 젓기/짜기/뿌리기 제스처는 한 번에 되돌립니다. 깨진 저장값은 컵케이크만 새로 시작합니다. 저장 불가 시 안내 후 놀이는 계속됩니다.

초기화 확인창에서 취소하면 유지합니다. 완료 후 ‘요리 선택으로’ 돌아가면 새 컵케이크를 시작하는 상태입니다. 완료 전에는 이어하기가 유지됩니다.

PNG는 1400×1400 투명 배경이며 케이크·선택한 크림·장식·접시만 저장합니다. UI·주방·축하 문구는 제외합니다. 화면과 PNG가 같은 `layout()`과 장식 좌표를 사용합니다. 자동 테스트에서 실제 SVG를 PNG로 래스터화한 결과와 다운로드 PNG의 픽셀 차이 및 투명 모서리를 비교합니다.

## 8. 공식 시안과 실제 화면의 차이

- 핑크 주방·나무 조리대·큰 중앙 음식·하단 재료 진열대·노란 현재 단계·초록 다음 버튼의 분위기를 유지했습니다.
- 시안의 재료 통/달걀 그림은 제공되지 않아 한글 카드입니다. 고품질 그림을 임의의 단순 도형으로 대체하지 않았습니다.
- 시안 B/C의 컵케이크 여러 개 대신 요청대로 큰 컵케이크 한 개를 사용합니다.
- 시안의 3단 받침대 대신 기존 검증된 접시를 사용합니다.
- 크림의 작은 중간 형태는 완성 PNG의 균일 축소입니다. 실제 짤주머니 줄이 쌓이는 애니메이션과는 차이가 있습니다.
- 바닐라용 짤주머니를 딸기에도 공통 도구로 사용합니다.
- 고품질 원본 그림에 맞춘 새로운 음식 에셋을 추가하면 재료 투입·굽기·크림 중간 과정의 시각 품질을 더 높일 수 있습니다.
