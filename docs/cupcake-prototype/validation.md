검증일: 2026-11-13. Windows의 설치된 Chrome, React + TypeScript + Vite 빌드 기준입니다.

| 검사 | 결과 |
| --- | --- |
| `tsc --noEmit` | 통과 |
| Vite production build | 통과 |
| `node scripts/verify-dist.mjs` | GitHub Pages 경로·매니페스트·오프라인 파일 검사 통과 |
| 전체 자동 테스트 | **270개 통과, 13.4분**. 기존 254개와 당시 컵케이크 16개 포함 |

현재 테스트 목록은 기존 254개 + 컵케이크 17개 = 271개입니다. 전체 실행 270개 이후 컵케이크만 추가 보완·재검증한 실행 순서를 구분하여 기록했습니다. CSS 마지막 보정은 작은 가로 화면의 단계 표시가 상단 뒤에 가려지지 않도록 쌓임 순서를 조정한 것입니다.

## 조작과 저장

- 실제 CDP 터치: 재료 선택, 약 4바퀴 젓기, 트레이 이동, 문 닫기, 길게 눌러 크림 짜기, 작은 장식 배치.
- 잘못된 크림 표면 입력 제한, 가로 진열대 스크롤 중 오배치 방지, 포인터 취소.
- 바닐라/딸기 변경 시 장식 좌표 유지, 제거/되돌리기 복원, 제스처 단위 이력.
- 새로고침/요리 선택 후 이어하기, 초기화 승인/취소, 다른 저장 키 유지.
- 굽기 도중 선택 화면·확인창에서 정지하고 저장 경과부터 재개.
- 키보드 조작, 저장 차단·손상 복구, 오프라인 새로고침.
- 실제 SVG 합성과 다운로드 PNG의 크림·장식·접시 구성 비교.

## 화면 및 시각 검수

1280×800, 1280×720, 360×800, 320×640, 800×360에서 도구 접근·48px 터치 대상·화면 잘림을 검사했습니다. 반죽 시작/젓는 중/완료, 컵 채움, 굽는 중/완료, 두 크림, 장식, 완성, 투명 PNG를 실제로 캡처하여 열어 보았습니다.

`reference-comparison.png`에서 공식 시안과 비교했습니다. 주방 색감과 음식 그림체는 제공 PNG를 통해 유지했습니다. 재료 그림, 사실적인 반죽 변화, 오븐 부품, 낮은/중간 크림 형태, 여러 컵과 3단 받침은 시안과 다르며 `README.md`에 추가 제작 자료를 구체적으로 기재했습니다. 자동 테스트 통과를 시안과 동일한 시각 품질 확보로 해석하지 않습니다.

Vite가 기존 대형 게임 번들에 대한 500kB 권장 크기 경고를 출력하지만 빌드는 성공합니다. 새 음식 가공본 13종의 합계는 약 12.6MB이며 최초 온라인 로딩과 오프라인 캐시 설치가 필요합니다.

## 미검증

실제 Galaxy Tab/스마트폰 하드웨어, Samsung Internet, Android 갤러리 반영, 오랜 시간 플레이했을 때의 저사양 기기 성능은 확인하지 못했습니다. 실제 기기 테스트 통과로 보고하지 않습니다. GitHub Actions 원격 결과는 PR에서 별도로 확인해야 합니다. 병합과 배포는 실행하지 않았습니다.
