# 코디놀이 착용 품질 개선

이번 수정은 계절·아이템 수 확대가 아니라 **바디, 의상 핏, 레이어와 정렬** 개선입니다. 기존 36개 아이템 ID와 옷장/계절 선택/드래그/되돌리기/초기화/사진 구조를 유지합니다. PR #9가 아직 미병합이므로 새 PR은 초기 구현과 이 개선을 모두 포함하여 main을 대상으로 합니다. 새 PR을 기준으로 검토하고, 이전 PR과 중복 병합하지 않습니다. 자동 병합·배포는 하지 않습니다.

## 1. 사람 캐릭터 구조

320×520 인형 좌표계 안에 머리·목·상체·골반·팔·손·다리·발을 분리했습니다. 어깨를 좁히고 손목/발 중심을 다시 맞췄습니다. 상의의 목둘레·어깨·소매 끝·옆선·밑단과 기본 바디가 같은 기준점을 사용합니다. 여자아이는 모자 아래 머리 폭을 정돈하고 긴 머리는 뒤쪽, 얼굴 옆 머리는 앞쪽에 분리합니다.

`rig.ts`가 캐릭터별 기준점, 허리선, 머리 폭, 앞뒤 발의 위치와 크기, 옷장 미리보기 범위를 관리합니다. 옷장과 본체, 드래그 그림, PNG는 모두 같은 맞춤 의상을 렌더링합니다.

## 2. 모자·상의·하의·신발

- 모자: 머리 폭에 맞게 크라운과 챙을 다시 그렸습니다. 야구모자·벙거지·밀짚모자·베레모는 머리 윗부분을 마스킹해 모자 위로 머리카락이 튀어나오지 않게 합니다. 챙 장식선도 의상 밖으로 내려오지 않도록 조정했습니다. 헤어밴드와 리본은 머리카락 위에 그대로 얹습니다. 안경은 별도 슬롯으로 눈 중심에 맞춥니다.
- 상의: 티셔츠의 짧은 소매, 셔츠의 좁은 커프스와 칼라, 후드티의 여유 있는 소매·후드·포켓, 카디건의 V자 앞판과 자체 이너를 구분했습니다. 실제 상의를 입으면 기본 티셔츠 전체를 숨깁니다.
- 하의: 골반/허리선 기준에 맞춰 바지의 가랑이·바짓단과 치마의 허리 밴드·주름·밑단을 수정했습니다. 원피스는 목에서 치맛단까지 연속된 실루엣, 투피스는 허리 밴드가 연결되는 전용 세트입니다.
- 신발: 사람은 좌우 발 중심을 각각 맞추고 바깥쪽을 향하도록 제작했습니다. 신발을 입히면 기본 신발은 숨깁니다. 강아지는 먼 발 두 개/가까운 발 두 개의 위치·크기·높이를 구별합니다.

## 3. 강아지 자세

몸은 왼쪽을 향한 측면, 얼굴은 정면을 바라봅니다. 긴 타원형 몸통의 왼쪽에 목과 얼굴, 오른쪽에 엉덩이와 꼬리를 두고 앞다리/뒷다리와 먼 쪽/가까운 쪽 다리를 나눴습니다. 각 발 아래에는 작은 접지 그림자를 둡니다.

상의는 목에서 등과 배를 감싸는 측면 패턴으로 제작했습니다. 조끼는 소매 대신 앞다리 구멍을, 니트는 목·배·소매의 시보리를, 하네스는 몸통을 두르는 벨트 구조를 사용합니다. 반바지/허리 리본은 뒷몸통에, 올인원은 몸통과 네 다리에 맞춥니다. 사람 의상을 강아지에 그대로 축소하지 않습니다.

## 4. 기본 런닝 노출 해결

기존 흰 런닝과 기본 반바지를 무조건 그리던 코드를 제거했습니다. 기본복도 인형의 실루엣에 맞는 **일상 티셔츠·반바지·신발**로 만들고, 실제 옷을 선택했을 때는 해당 기본복을 아예 그리지 않습니다.

- 하의만 입힌 경우: 기본 티셔츠는 허리선(330) 아래를 마스킹하여 하의 안으로 들어갑니다. 기본 반바지는 그리지 않습니다.
- 상의를 입힌 경우: 기본 티셔츠는 그리지 않습니다. 하의를 선택하지 않았다면 기본 반바지만 유지합니다.
- 원피스/투피스: 기본 티셔츠와 기본 반바지를 모두 그리지 않습니다.
- 카디건 안쪽의 밝은 천은 카디건 자체의 앞판/이너 그림이며, 기본 런닝이 밑단 밖으로 나온 것이 아닙니다.

## 5. 슬롯·레이어·저장 호환

슬롯을 `headwear`, `eyewear`, `top`, `bottom`, `footwear`, `onepiece`, `dogOutfit`으로 정리했습니다. 강아지 올인원은 전용 `dogOutfit` 슬롯입니다. 같은 슬롯은 교체하고, 원피스/올인원은 상의·하의를 해제합니다. 일반 상의·하의를 다시 고르면 원피스/올인원을 해제합니다. 모자와 안경은 동시 착용합니다.

사람은 뒤 머리 → 바디/팔/다리 → 필요한 기본 하의/선택 하의 → 필요한 기본 상의/선택 상의/원피스 → 손 → 신발 → 얼굴/앞 머리 → 안경 → 모자 순서입니다. 강아지는 꼬리/먼 다리 → 몸통/목/가까운 다리 → 전용 의상 → 얼굴 → 발별 신발/안경/모자 순서입니다. 무늬는 의상 실루엣 안에 클리핑합니다.

기존 저장 키와 아이템 ID는 유지합니다. 저장 형식은 version 2로 바뀌며, 이전 `hat/glasses/shoes/full` 슬롯과 되돌리기 기록을 읽어 새 슬롯으로 변환합니다. 이전 강아지 full은 dogOutfit으로 바뀝니다. 선택한 옷·캐릭터·사진 상태와 기록을 지우지 않습니다. 잘못된 데이터만 안전하게 새 상태로 처리합니다.

## 6. 드래그 착용

손가락을 따라가는 옷장 그림은 유지합니다. 호환 캐릭터 위에 가져가면 **몸에 맞는 실제 착용 미리보기**를 함께 표시합니다. 이 단계에서는 저장/되돌리기 기록을 변경하지 않습니다. 놓으면 동일한 앵커와 위치로 확정되므로 미리보기에서 착용 후 위치가 바뀌지 않습니다. 잘못 놓거나 취소하면 미리보기를 제거하고 기존 코디로 돌아갑니다. 클릭/터치 선택과 키보드 조작도 유지합니다.

## 8. 검사와 남은 한계

추가 검사는 눈과 안경 중심, 사람/강아지 각 발 중심, 모자 챙 높이와 머리 마스크, 하의 착용 시 기본복 숨김/허리 마스크, 원피스 충돌, 측면 몸통과 네 다리, 놓기 전후 위치 일치, 미리보기 미저장, 잘못된 대상 차단, 이전 저장/기록 변환을 확인합니다. 모든 54개 캐릭터별 선택지를 실제로 입혀 그림 비교표를 생성하고 육안 검토합니다. 기존 코디 조작·PNG·터치·오프라인 검사와 홈·색칠놀이·요리놀이 회귀 검사도 유지합니다.

고정 포즈용 2D 맞춤 에셋입니다. 자동 천 시뮬레이션은 아니므로 새 실루엣을 추가하면 개별 핏 검수가 필요합니다. 여름·가을·겨울과 아이템 확대는 이번 범위에 포함하지 않습니다. 실제 갤럭시탭/스마트폰의 손가락 조작, Android 갤러리 동작과 스피커 출력은 미검증입니다.
