# M05 2차 구조 개선 검수

아파트 단지의 기존 색감과 도로, 건물, 소방차 그래픽을 유지했습니다. 도로 연결과 건물 배치를 조정해 출발점에서 소방서까지 이어지는 단 하나의 경로에 세 화재 진압 지점이 차례로 놓이도록 설계했습니다.

[1차 전체 미로판](../04-board.png) · [2차 전체 미로판](04-board.png) · [유일한 정답 경로](solution.svg) · [오답 분기와 막다른 길](branches.svg)

## 도로 구조

| 항목 | 1차 | 2차 |
| --- | ---: | ---: |
| 이동 노드 / 무방향 연결선 | 66 / 74 | 67 / 66 |
| 교차로·갈림길 | 21 | 8 |
| 독립 순환 경로 수 | 9 | 0 |
| 연결선 하나만 있는 노드 | 6 | 10 |
| 정답에서 뻗는 오답 분기 | — | 5 |
| 갈림길을 포함하는 오답 분기 | — | 3 |

2차 막다른 길 10곳 중 8곳은 오답 분기의 끝이고, 나머지 두 곳은 출발점과 소방서입니다. 검수용 오답 도면에는 오답 분기의 끝 8곳을 붉은 원으로, 내부 갈림길 3곳을 청록 원으로 표시했습니다. 다섯 오답 분기의 진입점은 A–E이며, B·D·E 안에서 다시 길이 갈라집니다. 게임 화면의 도로는 같은 색과 형태를 사용합니다.

| 구간 | 지정 위치 (열, 행) | 거리 (SVG 단위) | 연결 수 |
| --- | --- | ---: | ---: |
| 출발 → 1번 건물 | 1,7 → 10,1 | 1,104 | 15 |
| 1번 → 2번 건물 | 10,1 → 7,4 | 737 | 10 |
| 2번 → 3번 건물 | 7,4 → 9,7 | 811 | 11 |
| 3번 → 소방서 | 9,7 → 7,6 | 959 | 13 |
| 합계 | | **3,611** | **49** |

정답 경로는 방향을 13회 바꿉니다. 자동 검사는 노드 전체의 연결, 자기 연결과 중복 연결, 시각적으로 교차하는 도로의 노드 공유, 연결선 수가 노드 수보다 하나 적다는 점을 확인합니다. 세 진압 지점을 하나씩 제거한 그래프에서는 각각 직전 지점에서 이후 목표와 소방서로 이동할 수 없습니다. 그래서 진압 순서는 도로 연결 자체에서 보장됩니다. 막다른 길에서 목표까지의 힌트는 분기 진입점으로 되돌아가는 방향을 먼저 가리킵니다. [공통 검증 코드](../../../src/games/firetruck-maze/roads.ts)

## 정차와 저장

- 진압 지점에 처음 닿을 때 현재 드래그를 종료하고, 방향키와 인접 위치 터치를 포함한 모든 이동을 잠급니다. 불끄기 버튼은 활성화되고 “불끄기 버튼을 눌러요!” 안내가 표시됩니다. 진압이 끝나면 새 입력으로 이동할 수 있습니다.
- 분사 도중 나가면 진압 전 상태에서 이어집니다. 목표 지점 위치를 복원할 때도 정차 조건을 다시 계산합니다.
- 지도 M05의 데이터 버전은 2이고, 새 기록은 `kids-game-playground:v1:game:firetruck-maze:r2`에 저장합니다. 이전 `r1` 값은 보존합니다. 이어갈 수 있는 새 기록 없이 이전 지도 버전의 기록이 발견되면 새 도로 안내를 표시하고 출발점부터 시작합니다.
