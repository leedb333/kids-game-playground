# 출동! 소방차 미로 최종 검수

10가지 도로와 건물 배치는 지도별 고정 데이터입니다. 미로판, 이동, 진압 위치, 힌트는 각 지도의 동일한 도로 연결 구조를 읽습니다. 게임 화면에는 지도 ID와 난이도가 표시되지 않습니다. 지도별 도면은 검수 문서에만 있습니다.

거리는 SVG 단위입니다. 최대 오답 깊이는 정답 경로의 진입점에서 막다른 길까지 지나야 하는 도로 연결 수입니다. 방향이 바뀌는 지점만 방향 전환으로 계산했습니다. 막다른 길 수는 출발점과 소방서를 제외한 값입니다.

모든 지도에서 도로가 하나로 연결되고 연결선 수가 노드 수보다 하나 적습니다. 진압 지점은 각각 출발–소방서의 유일 경로에 순서대로 있으며, 해당 지점을 하나씩 제거했을 때 직전 위치에서 이후 목표들로 갈 수 없음을 검사했습니다. 강을 건너는 M03의 도로는 다리 한 곳만 사용합니다. M08 호수와 M10 수변에는 횡단 도로가 없습니다. 신규 지도는 제시한 다섯 정량 지표 범위를 모두 충족했습니다. 화재가 두 개인 중 난이도 지도의 총 정답 거리는 M05보다 짧지만, 방향 전환·오답 선택지·되돌아와야 하는 길이 모두 늘었습니다. 실제 어린이의 체감 난이도와 소요 시간은 실기 검수가 남아 있습니다.

M05는 난이도 분류만 ‘하’로 바꿨습니다. 난이도를 제외한 지도 데이터의 직렬화 SHA-256은 2차 커밋과 일치합니다. 기존 정답 49개 연결선·3,611 SVG 단위·방향 전환 13회를 유지합니다.

## 테마와 호환성

- 주택가는 박공지붕과 정원, 공원 도시는 놀이터·산책로·운동장, 강변 도시는 물과 다리를 사용합니다. 상업 지구에는 차양이 있는 상점과 작은 광장이 있습니다.
- 학교와 병원은 학교 지붕 표식·운동장·병원 십자 표시를 사용합니다. 고층 빌딩과 대형 도심은 유리 외벽과 상점·광장을, 호수 주변은 호수와 녹지를, 복합 대도시는 주거·상업·공원·수변을 조합했습니다. 기존 SVG 구성 요소를 확장했고 외부 에셋은 추가하지 않았습니다.
- 미로 순환은 첫 출동, 확인된 새로 시작, 완료 후 다시 하기에서만 진행합니다. 한 순환에 10종씩 제공하며, 순환 경계에서 직전 지도를 제외합니다. 이어하기는 현재 위치·방향·목표·이동 경로와 남은 목록을 복원합니다.
- 시범판 r2의 M05는 지도 버전 2로 이어갈 수 있습니다. 이전 목록에 M05만 등록돼 있었거나 목록이 손상됐으면 현재 진행은 살리고 다음 출동 때 현재 지도를 제외한 목록을 다시 구성합니다. 이전 r1 값은 보존합니다. 신규 지도는 각자 데이터 버전 1로 시작합니다.

## 검증

TypeScript, Vite 배포 빌드, Pages 경로와 서비스 워커 검사를 실행했습니다. 브라우저에서 열 지도 각각을 오프라인에서 열고 진압과 소방서 복귀까지 완료했습니다. 기존 세 게임과 퍼즐 이미지 20장, 소리 설정 및 저장 기록을 확인했습니다. 독립 색칠·요리 앱의 운영 빌드를 같이 설치한 검사에서 기존 기록과 캐시가 보존됐습니다.

| 운영 빌드 | M05 2차 | 최종 10종 | 증가 |
| --- | ---: | ---: | ---: |
| dist 전체 | 11,637,225 B | 11,651,152 B | 13,927 B |
| JS·CSS 원본 합계 | 387,680 B | 401,607 B | 13,927 B |
| JS·CSS 파일별 gzip 합계 | 127,523 B | 131,586 B | 4,063 B |

갤럭시탭·스마트폰 실기는 진행하지 않았습니다. 화면 크기와 터치 입력은 Chromium에서 모의 확인했습니다. 최상 지도의 정차 위치·목표 번호 가독성, 기기 회전, 실제 탐색 시간은 실기에서 확인이 필요합니다.
