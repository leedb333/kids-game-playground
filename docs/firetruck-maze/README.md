# 출동! 소방차 미로 M05 시범 검수

[최종 10종 검수와 화면 캡처](final/README.md) · [2차 구조 개선 기록](v2/README.md)

아래 자료는 1차 시범판 기록입니다.

M05는 아파트 단지를 탐색해 1번, 2번, 3번 건물의 불을 차례로 끄고 소방서로 돌아오는 시범 미로입니다. 내부 난이도는 7이며, 어린이 화면은 출동 버튼으로 바로 시작합니다. 도시와 소방차, 지도, 분사 효과, 종합 홈 카드는 자체 SVG와 CSS로 제작했습니다. 시범 검수에 필요한 도로와 목표를 구분할 수 있어 현재로서는 별도의 일러스트 에셋이 필요하지 않습니다.

## 도로와 정답 경로

[도로 연결 및 최단 경로 도면](routes.svg)

위 도면은 개발 검수용입니다. 게임에서 힌트는 현재 위치부터 다음 1~2개 갈림길까지만 보여 주며, 이동하거나 약 5초가 지나면 사라집니다. 시작 화면과 게임 화면에는 전체 정답 지도가 표시되지 않습니다.

[지도 데이터](../../src/games/firetruck-maze/maps.ts)의 14열 × 9행 좌표는 왼쪽 위가 `0,0`입니다. 가로 간격은 74, 세로 간격은 73 SVG 단위입니다. 연결된 노드는 66개, 도로 연결선은 74개입니다. 막다른 길 6곳은 `0,2`, `4,0`, `11,0`, `13,4`, `6,8`, `0,6`입니다. 교차로·갈림길 21곳은 도로가 3개 이상 연결된 노드이며, 그래프의 독립 순환 수는 9개입니다. 시작은 `1,7`, 진압 위치는 `10,1` → `3,7` → `12,5`, 복귀 위치는 `6,1`입니다.

| 임무 | 최단 거리 (SVG 단위) | 도로 연결 수 |
| --- | ---: | ---: |
| 출발 → 1번 건물 | 1,104 | 15 |
| 1번 → 2번 건물 | 956 | 13 |
| 2번 → 3번 건물 | 812 | 11 |
| 3번 → 소방서 | 736 | 10 |
| 합계 | 3,608 | 49 |

도면은 도로 길이로 계산한 여러 최단 경로 중 하나를 구간별로 표시합니다. 경로가 겹치는 도로에서는 색을 구분하도록 경로선을 조금씩 평행 이동했습니다. 3~5분은 탐색을 포함한 설계 목표입니다. 실제 어린이의 플레이 시간과 난이도 체감은 실기 검수에서 확인해야 합니다.

## 조작과 진행

- 주 조작은 소방차를 잡고 끄는 방식입니다. 이벤트마다 현재 도로의 중심선에 위치를 투영하고, 노드에 닿았을 때 그 방향에 연결된 도로로 이동합니다. 마우스와 터치가 같은 이동 판정을 사용합니다. 다음 연결 위치를 한 번 누르거나 미로판에 초점을 두고 방향키를 누를 수도 있습니다.
- 지나온 길은 주황색 실선, 힌트는 노란 점선과 화살표입니다. 되돌아오거나 한 바퀴 돌아 같은 노드에 들어오면 그 구간의 선이 줄어듭니다.
- 목표 건물 앞의 정확한 노드에서만 2.35초 물 분사를 시작할 수 있습니다. 분사 중에는 소방차가 정지하고, 완료 시점에 체크 표시·수량·다음 목표를 함께 갱신해 저장합니다. 분사 완료 전에 창을 닫거나 새로고침하면 해당 화재부터 이어갈 수 있습니다.
- `kids-game-playground:v1:game:firetruck-maze:r1`은 미로와 저장 버전, 도로 위 위치·방향·경로, 진압 목록·목표·완료 상태, 미로 순환 상태를 담습니다. 드래그 종료, 한 칸 이동, 진압 완료, 화면 이탈 시 저장합니다. M05만 등록되어 있어 다시 출동하면 M05가 재시작됩니다.
- 이후 미로를 등록하면 순환마다 모든 미로를 한 번씩 선택합니다. 이어하기는 기존 순환과 미로를 복원합니다. 도로 검증에 더해 실제 어린이 세션에서 길 찾기 시간과 갈림길 사용성을 확인하고, 작은 화면에서 목표를 구분하기 어려운 경우 번호와 건물 아이콘 크기를 먼저 조정하는 것을 권장합니다.

## 화면과 테스트 환경

브라우저는 Chromium을 사용했습니다. 화면 크기는 CSS 픽셀이며 소방차는 회전 적용 전의 본체 치수를 측정했습니다. 터치 영역은 소방차 중심의 원입니다. 아래 값은 [브라우저 원시 측정값](measurements.json)을 반올림했습니다.

| 화면 | 미로판 | 도로 폭 | 소방차 | 터치 지름 |
| --- | ---: | ---: | ---: | ---: |
| 1280×800 | 1047×691 | 45.4 | 44×24 | 55.3 |
| 1280×720 | 930×614 | 40.3 | 39×21 | 49.1 |
| 800×360 | 394×260 | 17.1 | 17×9 | 44.0 |
| 360×800 | 344×227 | 14.9 | 15×8 | 44.0 |

스마트폰 세로 화면에서는 길과 차가 작게 보입니다. 소방차의 터치 영역은 본체보다 넓게 확보했고, 길 찾기가 어려우면 가로로 보는 편이 좋습니다. 자동 검사는 시뮬레이션이며 기기의 실제 입력 감도, 화면의 물리 크기와 어린이 사용성은 갤럭시탭과 갤럭시 스마트폰에서 별도로 확인해야 합니다.

```sh
pnpm build
node scripts/verify-dist.mjs
pnpm exec playwright install chromium
pnpm exec playwright test tests/firetruck-maze.spec.ts
pnpm test
```

검수 자료는 `docs/firetruck-maze/`에 있습니다. 운영 빌드는 기존 서비스 워커가 미로 코드와 스타일을 사전 캐시합니다. 미로 SVG가 게임 코드에서 생성되어 별도로 내려받는 에셋이 없습니다.

| 운영 빌드 | 기준 main | M05 추가 후 | 증가 |
| --- | ---: | ---: | ---: |
| 배포 파일 수 | 45 | 47 | 2 |
| dist 전체 | 11,608,537 B | 11,636,806 B | 28,269 B |
| JS·CSS 합계 | 358,992 B | 387,261 B | 28,269 B |
| JS·CSS 파일별 gzip 합계 | 116,505 B | 127,370 B | 10,865 B |

기준 main은 `b997db4c0c3bcea5d715d06d52d00df383c74ef4`입니다. 미로 전용 지연 로딩 JS와 CSS의 파일별 gzip 합계는 10,427 B입니다. 표의 gzip 값은 비교 목적이며 실제 전송량은 서버 압축 설정의 영향을 받습니다. 거리 도면과 캡처는 GitHub 검수 문서에만 포함됩니다.

PWA 검사는 기본 경로에서 최초 캐시 후 미로를 오프라인으로 처음 열고 이동하는 경우와, 같은 출처에 독립 색칠·요리 앱이 설치된 상태에서 기존 놀이터를 업데이트하는 경우를 확인합니다. 후자에서는 기존 그림 퍼즐 기록의 복원과 독립 앱 기록·캐시의 보존도 확인합니다.
