# 가로형 순서대로 색칠놀이 · 도안 버전 2

## 도안 구성

기존 다섯 주제를 유지하되, 세로 그림을 늘이거나 테두리만 추가하지 않고 1200×700 가로 장면의 독립 SVG 색칠 영역으로 새로 구성했습니다.

| 도안 | 가로 구성 | 색 수 | 영역 수 |
|---|---|---:|---:|
| 경찰차 로봇 변신 | 왼쪽 경찰차 → 오른쪽 로봇, 도로와 하늘 | 19 | 58 |
| 소방차 로봇 변신 | 왼쪽 소방차 → 오른쪽 소방 로봇 | 18 | 59 |
| 공룡과 알 | 넓은 공룡 몸과 꼬리, 오른쪽 알, 양쪽 나무 | 26 | 54 |
| 알록달록 나비 | 좌우로 펼친 날개, 양쪽 꽃과 꽃밭 | 28 | 58 |
| 장미꽃 | 좌우로 이어진 세 송이 장미와 잎·화단 | 28 | 54 |

새 그림은 원본 주제를 참고한 단순한 벡터 그림체입니다. 원본 이미지의 선과 세부 장식을 그대로 옮긴 그림은 아닙니다. 색상은 각 가로 장면에 맞게 정하고 번호는 빠짐없이 순서대로 진행합니다.

## 유지한 게임 방법

같은 숫자를 모두 칠하면 다음 색으로 자동 이동합니다. 힌트, 작은 영역 자동 확대, 확대·축소와 화면 밀기, 되돌리기, 확인 후 초기화, 자동 저장, 완성 축하, PNG 저장을 유지합니다. 완성 PNG는 1200×700 가로 이미지입니다.

태블릿에서는 왼쪽 넓은 도안·오른쪽 도구 배치를 유지합니다. 도안 선택 미리보기도 가로 비율로 바꾸고, 휴대폰에서는 작업판 높이를 가로 도안 비율에 맞춰 불필요한 아래 공백을 줄였습니다.

## 코드와 저장 기록

- 실제 사용 도안: `src/games/coloring/data/landscape.ts`
- 각 도안은 독립된 닫힌 SVG 경로, 안정적인 영역 ID, 숫자 위치를 가집니다.
- 새 도안은 revision 2, 영역 ID는 wide- 접두사를 사용합니다.
- 저장 키는 `kids-game-playground:v1:game:coloring:<도안ID>:r2`입니다.
- 이전 세로 도안의 r1 기록은 읽거나 삭제하지 않습니다. 가로 도안은 별도로 시작합니다.
- 기존 세로 도안 데이터 파일과 `source-hashes.json`은 최초 이식의 참고 기록으로 보존합니다. 해당 해시는 새 가로 도안의 동일성을 주장하는 기록이 아닙니다.
- 기존 kids-color-by-number 저장소는 변경하지 않았습니다.

## 검증

TypeScript·Vite 빌드·Pages 게시 파일 검사와 게임 자동 검사를 수행합니다. 도안별 모든 번호 위치에 대해, 해당 숫자를 터치했을 때 정확히 자기 색칠 영역에 닿는지 검사합니다. 완성 PNG는 파일 형식과 1200×700 크기를 확인합니다.

화면 캡처는 같은 폴더의 wide-*-start.png, *-complete.png, gallery-*.png, game-*.png에서 확인할 수 있습니다. 실제 갤럭시 기기 검수와 공개 배포는 아직 하지 않았습니다.

최종 검증: 로컬 자동 검사 36개 통과. 마지막 소방차 세부 수정 후 해당 도안 검사 4개도 통과했습니다. 도안별 숫자 위치·실제 터치·번호 순서·기록 분리·오프라인·가로 PNG 크기·다섯 화면 크기를 확인했고, 다섯 완성 이미지를 직접 열어 검수했습니다.
