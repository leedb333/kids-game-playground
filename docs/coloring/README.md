# 가로형 순서대로 색칠놀이

## 가져온 내용

기존 `kids-color-by-number` 로컬 작업 폴더 `app/src`에서 도안 데이터·SVG 표시 코드·PNG 저장 코드·색칠 규칙을 새 앱의 `src/games/coloring`으로 복사했습니다. 기존 앱 파일과 저장소는 수정하지 않았습니다.

정식 도안 5개: 경찰차 로봇 변신, 소방차 로봇 변신, 공룡과 알, 알록달록 나비, 장미꽃. 각 28색이며 모든 영역·윤곽선·색상·순서·숫자 위치·원래 도안 비율을 보존했습니다. `source-hashes.json`에는 복사본과 원본의 내용이 같음을 확인한 SHA-256 기록이 있습니다. SVG 표시 및 PNG 저장 코드도 원본과 동일합니다.

기존과 같은 게임 방법: 현재 숫자의 영역만 칠할 수 있고, 같은 숫자의 영역을 모두 칠하면 다음 색으로 자동 이동합니다. 힌트, 작은 영역 자동 확대, 수동 확대·축소, 화면 밀기, 한 칸 되돌리기, 확인 후 초기화, 자동 저장, 완성 축하, 완성 PNG 저장을 유지합니다.

## 새 앱에 맞춘 변경

- 홈의 색칠놀이 카드만 실행 가능. 다른 게임은 준비 중 유지
- 하늘색 배경, 분홍 테두리, 흰 작업판과 둥근 도구 버튼
- 태블릿 가로에서는 왼쪽 도안과 오른쪽 색상·진행·도구 패널
- 휴대폰 세로에서는 위아래 배치와 가로 스크롤 색상표
- 공통 홈·소리 메뉴는 작게 유지하며 도안 선택으로 돌아가기 제공
- 도안과 게임 기능은 별도 모듈로 불러오며 PWA에서 색칠놀이 파일까지 미리 저장
- 저장 키만 `kids-game-playground:v1:game:coloring:<도안ID>:r<버전>`으로 변경. 기존 앱 저장 기록을 덮어쓰거나 자동으로 가져오지 않음
- 게임 파일을 불러오지 못할 경우 놀이터로 돌아가는 오류 안내

소리 버튼은 기존 공통 설정을 유지합니다. 이번 버전에는 효과음·배경음이 없습니다. 홈이나 도안 선택으로 이동해도 진행은 이미 자동 저장되어 있습니다.

## 확인 방법

홈 → 순서대로 색칠놀이 → 도안 선택 → 현재 숫자를 톡 누르세요. 작은 숫자는 힌트를 누르면 확대되고 해당 영역으로 이동합니다.

빌드 후 `pnpm test`로 자동 검사를 실행합니다. 실제 갤럭시 기기의 삼성 인터넷·Chrome 및 다운로드 폴더 확인은 배포 승인 후 진행해야 합니다. 기존 배포 주소에는 PR 병합과 별도 수동 배포 전까지 이 변경이 보이지 않습니다.

## 검증 결과 (2026-11-05)

- TypeScript 검사·프로덕션 빌드·Pages 게시 파일 검사 통과
- Chrome 모의 터치 환경 자동 검사 총 30개 통과 (홈 7개 포함)
- 5개 도안의 모든 색상 순서와 잘못된 저장 데이터 거부 검증
- 각 도안에서 실제 터치, 잘못된 색상 방지, 이어하기, 되돌리기, 초기화 확인·취소 검증
- 각 도안의 마지막 영역을 칠해 완성하고 실제 PNG 파일 서명·1200px 너비 확인
- 1280×800, 1280×720 태블릿 가로: 페이지 스크롤 없이 작업실과 도구가 한 화면에 들어옴
- 360×800, 320×640 휴대폰 세로, 800×360 휴대폰 가로: 가로 넘침 없음, 도구 높이 48px 이상
- 오프라인에서 게임 최초 열기·재접속·진행 복원, 다른 도안 및 이전 앱 저장 키 분리, 저장 차단 시 계속 색칠 가능 확인
- 태블릿과 휴대폰 캡처 직접 확인. 실제 갤럭시 기기 검수와 공개 배포는 아직 하지 않음

도안 데이터가 포함된 게임 파일은 약 985KB(압축 약 388KB)입니다. 홈과 별도 파일로 불러오며, 오프라인 사용을 위해 서비스 워커가 미리 저장합니다.
