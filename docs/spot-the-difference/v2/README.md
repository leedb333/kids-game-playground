## 초기 설치와 오프라인

선택 화면은 10개 썸네일을 요청합니다. 초기 PWA 사전 캐시는 기존 네 게임과 앱 셸, D01의 JSON과 두 게임용 이미지, 전체 썸네일을 포함합니다. D02~D10의 원본·변경본과 JSON은 해당 그림을 처음 온라인에서 열 때 가져옵니다. 두 그림이 모두 정상 디코딩되면 별도의 버전별 URL로 저장합니다. 최신 버전의 세 파일 중 하나라도 없으면 오프라인 안내를 표시합니다. 온라인 재진입에서 누락된 한 파일만 내려받아 복구하는 흐름도 확인했습니다.

직전 D01 시범판에서 v2로 업데이트하고 D01 진행 및 캐시 범위가 유지되는지 검증했습니다. 기존 서비스 워커 정책은 유지합니다. 브라우저 저장 공간이 부족하거나 캐시가 비워지면 해당 그림을 온라인으로 다시 열어야 할 수 있습니다.
