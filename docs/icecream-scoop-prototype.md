- 컵/콘 크게 선택, 선택 테두리, 이전 단계로 돌아가 용기를 바꿔도 스쿱 순서 보존.

- 가로 진열대 스크롤과 드래그 구분. 취소·영역 밖 드롭은 상태 불변. 터치 후 합성 click 중복 억제 및 키보드 click 지원.
- 처음부터 다시 확인/취소, 1~3스쿱에서 다음 단계 안내창(토핑 실제 구현 아님).
- 소리 설정 및 자동 저장. 전용 키 kids-cooking-v2-icecream-v1, version1, container/scoops/step/sound. 손상되거나 잘못된 저장값은 안전한 새 상태, 저장 차단 시 안내.
- composition.ts가 원본 PNG를 변경하지 않고 알파 경계를 구한 후 PR33의 고정 좌표로 합성. 800×1160 좌표계, 컵폭400·스쿱폭430·바닥900·상승215, 콘폭330·스쿱폭360·바닥770·상승170. 음식 그룹 전체만 화면에 맞춰 축소. 같은 render 함수를 추후 PNG 출력에 사용할 수 있다.
- pastel CSS 매장, 독립 버튼/카드/음식, 4단계 표시 중 앞2단계만 활성. 작은 가로 스마트폰은 오른쪽 재료 패널로 조리 높이 확보.

타입·운영 빌드 및 scripts/verify-dist.mjs 통과. 기존 큰 bundle 경고는 유지. 승인18종 이미지 및 기존게임 소스 변경 없음. 기존254개 전체검사·구요리·코디 검사 미실행. 실제 삼성 기기 테스트 미실행.

## 시각 품질과 범위 한계

스쿱 겹침·색 구분·원본 비율·상단 여백을 실제 캡처로 확인. 정식 시안보다 배경은 단순하고, 단일 스쿱의 공간은 나중에 올릴 세 스쿱 높이를 위해 비워 둔다. 특히 작은 가로폰의 음식은 태블릿보다 작다. 원본17종의 일부 디테일은 약330px 소스 한계를 유지한다. 전용 고품질 매장 배경은 이후 제작한다.

토핑 꾸미기, 완성 화면, PNG 다운로드, 새 경로의 전용 오프라인 진입, 정식 홈 등록은 이번 범위가 아니다. 다음 정식 개발에서는 토핑 조각 단위·개수·마스킹, 완성 PNG와 동일 좌표, 전용 배경, 캐시와 실기 터치 성능을 검증한다. 기존 게임·저장·PWA 배포 정책은 변경하지 않았다.
