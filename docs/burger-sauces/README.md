## 2. PNG 검수 결과

세 파일 모두 **1448×1086 PNG, RGBA(색상 타입 6)**이며 실제 투명 배경과 반투명 가장자리를 갖습니다. 윤기 있는 지그재그 그림체와 색상이 기존 음식에 어울립니다. 기존 24종에 추가해 총 27종을 로딩하고, 실제 화면에서는 예비 소스 그릇 3종을 제외한 24종을 사용합니다. 큰 투명 여백과 낮은 알파의 외곽 색 점이 있어 원본을 보존하고 게임용 가공본만 정리했습니다.

| 소스 | 원본 완전 투명 픽셀 비율 | 정리한 외곽 픽셀 | 가공 크기 |
|---|---:|---:|---|
| 케첩 | 83.2% | 11,324 | 1286×388 |
| 마요네즈 | 81.3% | 19,774 | 1303×397 |
| 머스터드 | 82.1% | 10,040 | 1291×400 |

가장 큰 소스 연결 영역과 1픽셀 가장자리를 유지하고 떨어진 점을 제거한 뒤 2픽셀 여유를 두고 잘랐습니다. 유지한 영역의 원래 RGB와 반투명 알파는 바꾸지 않아 음식 가장자리의 부드러움을 보존했습니다. 전체 배경을 불투명하게 바꾸거나 굵은 CSS/SVG 선으로 대체하지 않았습니다.

[원본 SHA256·크기·투명도 검사표](asset-audit.json)에 기록했으며 테스트에서도 원본 해시가 같은지 확인합니다. 원본이 추후 교체되면 검사표와 가공본을 다시 생성해야 합니다.

## 3. 뿌리기와 층 순서

기존 소스 탭에서 병을 선택한 뒤 햄버거를 누르거나, 병을 햄버거로 끌어 놓습니다. 해당 소스 PNG가 현재 가장 위 재료에 연결됩니다. 아랫빵만 있을 때는 아랫빵에 연결됩니다. 재료마다 표시 폭의 약 82~87%로 줄이고 표면의 앞부분에 놓아 옆에서 보는 햄버거 시점에 맞췄습니다. 음식 좌표를 기준으로 위치를 계산하므로 햄버거가 축소되어도 함께 움직입니다.

소스에는 고유 ID, 종류, 적용 순서, 지지하는 층 ID(`after`), 가로·세로 보정 위치, 표시 배율과 회전을 저장합니다. 손가락 위치는 음식 밖으로 벗어나지 않는 범위로 보정합니다. 반복 사용 시 약간의 위치·크기·각도 차이를 주지만 저장된 수치를 재사용하므로 다시 열 때 임의로 바뀌지 않습니다.

공통 `layout(layers, complete, applications)`는 각 재료 바로 뒤에 그 재료의 소스들을 그립니다. 이후 재료와 윗빵은 그 뒤에 그려져 소스를 자연스럽게 가립니다. 소스가 항상 맨 위에 뜨지 않습니다. 내부에 가려지는 소스도 기록과 PNG 합성에 남아 있습니다.

소스는 음식 높이나 **재료 16층 제한을 사용하지 않습니다. 소스 횟수 제한도 없습니다.** 기존 시험판이 최근 60개 소스만 보관하던 처리를 제거했습니다. 다만 브라우저 저장 공간을 초과하면 기존과 같이 저장 불가 안내를 표시하며 플레이는 계속됩니다. 되돌리기 이력은 기존처럼 최근 60개 편집을 유지합니다.

## 4. 제거·되돌리기·호환성

- 소스를 뿌린 직후 되돌리면 해당 사용만 취소됩니다.
- 기존 '재료 빼기'의 하단 목록에서 `소스 2 마요네즈 빼기`처럼 각 소스를 골라 제거할 수 있습니다. 다른 소스는 유지됩니다.
- 지지하는 재료를 제거하면 연결된 소스는 바로 아래 재료(없으면 아랫빵)로 내려옵니다. 공중에 남거나 사라지지 않습니다.
- 제거를 되돌리면 원래 재료·소스 ID·순서·연결·위치를 복원합니다.
- 기존 **version 1 및 저장 키를 그대로 유지**합니다. 예전 소스 기록에 위치 정보가 없으면 기본 위치를 적용하고 음식과 기록은 유지합니다. 예전 기록에서 삭제된 층을 가리키면 남아 있는 아래 층으로 복구합니다. 잘못된 값은 기존 저장 검증 정책으로 처리합니다.

## 5. 완성 화면과 PNG

완성할 때 다른 햄버거 그림으로 바꾸지 않습니다. 실제 재료와 소스를 유지하고 윗빵만 추가합니다. 소스가 없으면 임의로 추가하지 않습니다. SVG 화면과 Canvas 출력은 같은 스프라이트 배열·표시 순서·좌표·회전을 사용합니다.

PNG는 기존과 같은 **1400×1400, 투명 배경, 음식과 접시만** 저장합니다. 배경·버튼·설명·병·축하 효과는 포함하지 않습니다. 저장 직전 구성의 복사본을 사용하므로 저장 도중 화면을 떠나도 결과가 바뀌지 않습니다. 실제 SVG를 동일한 크기로 래스터화한 이미지와 다운로드한 PNG의 픽셀 차이를 검사합니다(렌더러별 미세한 보간 차이는 허용).

## 8. 남은 제한

소스는 제공된 PNG를 합성하는 2D 표현으로, 실제 액체처럼 재료 표면을 따라 흐르거나 형태가 변하지 않습니다. 후속 재료가 넓으면 앞쪽에 드러나는 부분만 보이고 나머지는 가려집니다. 원본 간 시점·해상도 차이와 그룹 재료의 한 묶음 단위 동작은 기존 시험판과 같습니다. 새 기능 확장이나 화면 전면 개편은 하지 않았습니다.
