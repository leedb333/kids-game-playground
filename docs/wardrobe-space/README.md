# 코디놀이 아이템 공간 확대

## 변경 내용

- 옷장 하단의 **지금 입은 옷** 영역을 화면에서 완전히 제거했습니다.
- 옷장 제목의 보조 문구를 숨기고, 캐릭터 미리보기와 제목 줄을 32px로 정리했습니다.
- 카테고리 탭을 아이콘·글자 가로 배치로 바꾸고 위아래 여백을 줄였습니다.
- 아이템 이미지와 위로/아래로 버튼은 줄이지 않았습니다. 버튼은 계속 48px 이상입니다.
- 드래그 착용은 그대로이며, 입은 아이템을 다시 눌러 벗을 수 있습니다. 되돌리기와 초기화도 유지합니다.
- 사계절·세 캐릭터·모든 카테고리에 공통 적용했습니다.

옷장 전체 크기나 왼쪽 캐릭터 공간을 늘리는 대신, 옷장 안에서 아이템 목록이 차지하는 높이를 늘렸습니다. 저장 형식과 의상 데이터·착용 앵커는 그대로입니다. 다른 게임의 코드·스타일·배포 설정은 변경하지 않았습니다.

모든 계절·캐릭터·카테고리에서 하단 영역이 없는지, 옷장 제목이 36px 이하인지, 1280×800에서 아이템 목록이 280px 이상인지 자동 검증합니다. 1280×720에서도 목록 높이가 240px 이상인지 검사합니다. 스크롤 막대가 숨겨져 있어도 모든 아이템에 접근하고, 마지막 아이템의 터치 착용과 다시 눌러 벗기기를 확인합니다.

실제 갤럭시탭·스마트폰은 미검증입니다. 브라우저 화면 크기와 터치 이벤트로 검증합니다. 자동 병합·배포하지 않습니다.

TypeScript 검사·Vite 빌드·Pages 경로 검증을 통과했습니다. 기존 코디놀이 검증 51개와 공간/목록/터치 검증 8개가 모두 통과했습니다.
