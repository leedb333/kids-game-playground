# 승인 도안 적용 결과

경찰차·공룡·꽃과 나비는 승인된 미리보기 원본을 그대로 배경 에셋으로 사용합니다. 소방차만 같은 도시 배경에서 조금 크게 수정했습니다. 원본 파일은 수정하지 않고 별도 SVG 색칠 영역을 겹칩니다. 그림 전체를 클릭하는 방식이 아닙니다.

| 도안 | 색칠 대상 | 고정 배경 | 색 / 영역 | 캔버스 |
|---|---|---|---|---|
| 경찰차 | 경찰차 | 푸른 도시·시계탑·도로 | 25 / 186 | 1200×840 |
| 소방차 | 크기를 조금 키운 소방차 | 벽돌 소방서·도시·도로 | 25 / 223 | 1200×839 |
| 공룡 | 공룡과 좌우 두 나무 전체 | 하늘·언덕·바닥·풀·돌 | 28 / 130 | 1200×800 |
| 꽃과 나비 | 다리 없는 나비와 앞쪽 꽃·줄기·잎 | 뒤쪽 꽃밭 | 28 / 180 | 1200×700 |

배경에는 번호·색칠 이벤트·진행률을 적용하지 않습니다. 공룡의 나무 밑동과 크림색 입 부분도 독립 색칠 영역으로 분리했습니다. 작은 장식과 윤곽선은 고정 원화로 보존합니다. 색상은 25~28색 팔레트로 정리되므로 완성 결과는 원화의 세부 음영과 약간 다를 수 있습니다.

## 게임과 저장

색상 순서, 다음 색 자동 선택, 힌트, 되돌리기, 초기화, 자동 저장, 완성 PNG 저장을 제공합니다. 새 도안은 revision 4로 저장해 이전 도안 진행 기록과 분리합니다. 이전 저장 기록은 삭제하지 않습니다. 처음 한 곳만 칠한 상태도 이어하기로 표시합니다.

고정 배경 PNG 4개를 서비스 워커에 미리 저장하며, 완성 PNG에는 배경을 함께 포함합니다. 배경 파일 내용도 캐시 버전에 반영합니다. 최초 온라인 저장이 끝난 뒤 오프라인으로 게임 실행·이어하기·PNG 저장을 할 수 있습니다.

## 검증

태블릿 1280×800, 1280×720 및 휴대폰 가로·세로 크기를 브라우저로 검증했습니다. 실제 갤럭시 기기 검증은 별도로 필요합니다. 자동 검증은 색칠 규칙, 모든 번호 위치의 실제 터치 대상, 저장·복구, 고정 배경 클릭 무반응, 오프라인 실행과 배경 포함 PNG를 확인합니다.

- `game-tablet.png`, `game-phone.png`: 반응형 화면
- `wide-*-start.png`: 실제 시작 상태
- `*-complete.png`: 실제 게임에서 저장한 완성 이미지
- `*-manifest.json`: 변환 영역과 원본 해시

원본 경찰차·공룡·나비는 `../coloring-v4-preview/`, 확대 소방차는 `fire-city-larger.png`입니다. 이전 원화와 생성 지시는 `../coloring-v3/`에 보존합니다. 변환 도구는 `scripts/coloring-scenes/`에 있습니다.

작업은 PR #3에서 검토합니다. 자동 병합·배포는 하지 않습니다. 기존 kids-color-by-number 저장소는 변경하지 않습니다.
