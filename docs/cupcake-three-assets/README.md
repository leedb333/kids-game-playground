## 가공 방법·검증

- 사용자 폴더의 `.png.png` 원본은 읽기만 했습니다. 파일명을 명세의 단일 `.png`로 정리했습니다.
- PNG 시그니처/실제 크기/색 유형 6(RGBA), 완전 투명 픽셀과 반투명 픽셀을 확인했습니다. 화면의 검정 표시를 불투명 검정 배경이라고 오인하지 않았습니다.
- 크기 120픽셀 미만의 분리된 작은 알파 연결 성분을 제거하고, 알파 8 미만의 매우 희미한 잡점을 제거했습니다. 피사체 연결 영역의 색상은 임의로 지우지 않았으며 의미 있는 큰 우유 방울 등은 유지했습니다. 전체 비율·캔버스 위치를 유지했습니다.
- 승인 카드 4장은 1254² 전체 캔버스를 1024²로 축소했습니다. 경계에 알파>32인 픽셀 0개, 투명 영역과 반투명 가장자리 존재, 출력 PNG RGBA를 자동 확인했습니다. 투명 체크무늬/짙은 배경 미리보기에서 외곽과 가독성을 직접 확인했습니다. 모든 가장자리 결함이 수학적으로 사라졌다는 의미는 아닙니다.
- 승인된 카드 그림 자체(분홍 프레임·한글 포함)는 보존했습니다. 이는 카드용 통과이며, 볼에 들어가는 재료 그림으로 사용한다는 뜻은 아닙니다. 기존 명세의 용기 예시와 차이는 있지만 사용자가 승인한 카드 구성을 유지했습니다.
- 원본 13장 SHA-256을 가공 전후 비교해 보존을 확인했습니다. 입력·출력 크기, 투명 픽셀 수, 제거량, 승인 카드 출력 해시는 `audit.json`에 기록했습니다.
- 기존 컵/볼 원본은 비교에만 사용했습니다. 게임 소스, 기존 public 에셋, 저장 데이터, 홈, 배포 설정의 diff가 없는지 확인했습니다. 새 에셋은 게임에서 아직 참조하지 않습니다.

## 컵 상태 정렬 검수 — 불합격

`cups-review.png` 위쪽은 같은 캔버스의 나란히 보기, 아래쪽은 각 후보와 기존 완성 컵의 50% 중첩입니다. 기존 파일 `cupcake-baked-base.png`와 동일한 1254² 원본 좌표를 유지한 비교입니다.

- 새 빈 컵/생반죽 컵은 입구가 더 넓고 높습니다. 앞쪽 주름의 폭·하트 크기·중앙 하트 높이도 기존 원화와 다릅니다.
- `filled`는 반죽을 낮게 담은 상태가 아니라 둥글고 노릇한 완성 케이크입니다. `half-baked`는 부풀기 전 생반죽 모습입니다. 이름만 바꿔도 고정 종이컵 불일치는 해결되지 않습니다.
- 중첩에서 바닥·측면·하트가 이중으로 보입니다. 단순 이동/전체 배율 조정만으로 모든 특징을 동시에 고정할 수 없습니다.

**재제작:** 기존 완성 컵 원본의 종이컵 부분을 그대로 보존한 편집으로 빈 컵/낮은 생반죽/연노랑 반쯤 부푼 케이크를 만드세요. 1254² 공통 캔버스와 바닥 위치를 유지하고 내용물만 바꿔야 합니다. 또는 공통 종이컵 앞면과 내용물만 분리하는 방식을 별도 검증할 수 있습니다.

## 볼·재료 합성 검수 — 불합격

`bowl-review.png` 위쪽은 새 빈 볼과 4개 재료를 같은 원본 좌표로 합성한 결과입니다. 노른자·우유·가루·설탕이 모두 볼 앞 테두리와 장식을 덮어 볼 바깥에 떠 있는 형태가 됩니다. 아래쪽은 기존 반죽 볼과 새 빈 볼의 나란히 보기 및 중첩입니다.

- 새 볼은 추가 곡선 장식, 다른 세로 주름, 다른 깊이와 받침 구조를 갖고 있습니다. 기존 최종 반죽 볼과 같은 그릇으로 전환되지 않습니다.
- 레이어 파일 자체의 분리·질감은 활용 가능성이 있으나, 현재 공통 좌표로 즉시 올리는 에셋 검수는 실패입니다. 볼 내부 앵커/배율/앞면 가림이 확정되지 않았으므로 업로드하지 않았습니다.

**보완:** 먼저 기존 반죽 볼의 외곽/하트/받침을 보존한 빈 볼을 확보하세요. 이후 4개 재료를 그 볼 내부의 동일한 표면 기준으로 재배치하고 앞 테두리에 필요한 가림 마스크를 함께 검증해야 합니다. 재료는 반드시 다시 그려야 하는 것은 아니며, 재배치·마스킹으로 해결할 수 있는지 다음 검수에서 판단합니다. 네 레이어를 동시에 쌓거나 섞는 실제 게임 동작은 이번 작업에서 구현하지 않았습니다.

## 트레이 검수 — 불합격

제공 트레이에는 컵 3개가 이미 그려져 있습니다. 명세는 컵이 없는 트레이와 3개 자리만 필요합니다. 이 이미지를 게임에 쓰면 개별 컵 상태와 중복되고 이동/굽기 때 종이컵이 바뀌어 보입니다. 컵을 지우면 가려진 트레이 바닥을 새로 그려야 하므로 단순 누끼 작업으로 합격 처리하지 않았습니다.

**재제작:** 투명 RGBA 1800×1000, 컵과 음식 없이 가로 3구 자리만 있는 분홍 트레이. 세 구멍은 같은 깊이·시점, 기존 컵을 별도로 얹을 공간 확보.
