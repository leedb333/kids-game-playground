## 구현과 검증

인접 조각은 같은 SVG 곡선을 반대 방향으로 사용합니다. 전체 퍼즐을 완성하면 원본 그림이 이어진 상태로 표시됩니다. 마우스나 터치로 끌거나 조각과 자리를 차례로 눌러 놓을 수 있습니다. 보관함의 그림 부분을 세로로 밀면 스크롤되고, 손잡이를 끌면 조각이 움직입니다.

저장은 `kids-game-playground:v1:game:jigsaw-puzzle:<imageId>:r1` 키에 그림·난이도·배치 이력·남은 순서·완료 여부·형식 버전을 보관합니다. 잘못된 저장 형식은 새로 시작할 수 있게 처리합니다. 다시 시작은 확인한 뒤 해당 그림만 초기화합니다.

기존 서비스 워커가 처음 준비될 때 퍼즐 WebP 20장의 응답을 사전 캐시합니다. 브라우저에서 그림을 표시하고 디코딩하는 시점은 난이도·그림 화면에 들어간 뒤입니다. 서비스 워커 범위와 다른 앱의 캐시 격리는 기존 방식과 같습니다.

```sh
pnpm build
node scripts/verify-dist.mjs
pnpm exec playwright test tests/jigsaw.spec.ts
```

캡처는 Chromium 뷰포트와 모의 터치로 만들었습니다. 32조각의 스마트폰 가로 화면에서는 각 열이 약 25px로 좁아집니다. 지정된 4×8 구성은 유지했으며, 갤럭시 실기에서 조작 정확도를 확인하고 필요하면 보드 확대를 검토할 수 있습니다.
