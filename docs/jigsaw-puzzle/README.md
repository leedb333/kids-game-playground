## 터치와 저장

이전의 6개 점은 `touch-action: none`으로 세로 드래그를 시작하는 영역이었습니다. 이제 그 역할은 조각 그림에 직접 적용됩니다. 보관함 오른쪽 여백과 조각 사이에서는 브라우저의 세로 스크롤이 작동합니다. 조각을 잡은 SVG 좌표를 유지하고, 드래그 그림만 퍼즐판 배율에 맞춥니다. 조각 제거 후 보관함의 스크롤 위치는 유지됩니다.

1~3단계는 기존 `:r1` 기록을 읽습니다. 다시 저장할 때 행·열·조각 수를 기록합니다. 4~5단계 새 배열은 퍼즐별 `:r2`에서 시작하며, 24·32조각의 `:r1` 기록은 그대로 보존합니다. 유효한 옛 완료 기록은 카드에 **이전 퍼즐 완성**으로 표시됩니다. 새 배열의 진행이나 완료 상태와 독립적입니다.

## 검사 및 배포

로컬 전체 Chromium 회귀 79개가 통과했습니다. 소형 화면의 보관함 스크롤 여백을 최종 조정한 뒤 퍼즐 테스트 11개를 다시 실행해 모두 통과했습니다. 실제 터치 이벤트로 여백의 세로 스크롤, 조각 자체 드래그, pointercancel, 20조각 맞춤 후 위치 유지, 스마트폰 가로 25조각 드래그와 회전 후 진행 유지도 확인했습니다. 기존 두 게임, 저장과 소리, 독립 색칠·요리 앱 캐시와 저장값, 오프라인 퍼즐과 20개 사전 캐시 이미지도 검사했습니다.

프로덕션 빌드 파일은 전후 45개, 사전 캐시 URL은 35개입니다. 전체 파일 용량은 11,601,327 B에서 11,606,572 B로 5,245 B 늘었습니다. 외부 라이브러리와 새 배경 이미지는 추가하지 않았습니다. 이 검수 자료는 `docs/`에 있어 Pages 빌드에 복사되지 않습니다.

갤럭시탭 실기에서는 그림을 잡기 쉬운 정도, 색이 있는 조각과 스크롤 여백의 구분, 장시간 드래그, 효과음, 설치 앱에서 업데이트 후 이어하기를 확인해야 합니다. 이 문서의 기기별 캡처는 Chromium 모의 화면입니다.
