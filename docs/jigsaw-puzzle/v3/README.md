## 외곽 비교

- [3단계 16개 전체](silhouettes-3.svg) · [4단계 20개 전체](silhouettes-4.svg) · [5단계 25개 전체](silhouettes-5.svg)

각 표의 첫 그룹은 이전 공통 외곽, 이후 네 그룹은 그림별 새 외곽입니다. 색과 배경을 제외하고 같은 배율에서 동일한 조각 번호를 비교합니다. 결합부 중심은 경계 길이의 38%·50%·62% 중에서 정하며, 너비와 목, 깊이, 비대칭 곡선을 조합합니다. 이미지 ID·격자·형상 버전의 고정 시드를 사용합니다. 인접한 두 조각은 하나의 Bézier 경계를 반대 방향으로 공유합니다. 바깥 경계는 평평합니다.

형상 비교는 격자 원점을 빼고 Bézier 제어점을 정규화합니다. 여기에 결합부 방향·위치의 패턴도 비교하여 미세한 좌표 차이만으로 중복을 피해 가지 않도록 했습니다. 두 검사를 통과할 때까지 전체 공유 경계를 다시 만들며 최대 32회 후에는 오류를 보고합니다. 이번 12개 그림은 모두 통과했습니다.

## 크기 측정

같은 Chromium 뷰포트에서 단계별 첫 그림을 열었습니다. 단위는 CSS px이고 조각 크기는 외곽 사각형의 가로·세로 중앙값입니다. [측정 원자료](measurements.json)

## 저장과 배포

1~2단계의 형상과 `:r1` 기록을 유지했습니다. 3단계의 `:r1`과 4~5단계의 `:r2` 중 동일 격자로 검증된 기록은 조각 ID·배치 이력·남은 순서·완료 여부를 그대로 `:r3`에 이어 씁니다. 새 기록은 플레이를 열 때 작성하며 원본 키는 보존합니다. 같은 조각 수라도 격자가 다른 기록은 복원 대상에서 제외됩니다. 이전 24·32조각의 완료 배지도 유지했습니다.

배포 파일은 전후 45개, 사전 캐시 URL은 35개입니다. 배포 용량 합계는 11,606,572B에서 11,608,537B로 1,965B 늘었습니다. 비교 자료는 `docs/`에 두었습니다.

로컬 Chromium 전체 회귀 82개가 통과했고 최종 진행률 표시 조정 후 관련 검사 15개가 다시 통과했습니다. 타입 검사, 운영 빌드와 Pages 검사도 통과했습니다. 이전 운영 빌드에서 새 서비스 워커로 전환한 뒤 오프라인 20조각 이어하기와 원본 저장값 보존, 독립 색칠·요리 앱의 캐시·저장 격리를 확인했습니다.

갤럭시탭 실기에서는 그림이 비슷한 조각의 구분, 직접 드래그와 여백 스크롤, 설치 앱 업데이트 후 이어하기를 확인해야 합니다. 이 자료의 터치와 화면 크기는 Chromium 모의 결과입니다.
