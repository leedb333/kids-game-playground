# 직접 만드는 피자 · 두 번째 플레이 버전

버튼 한 번으로 단계를 완료하던 피자를 실제 도구 조작 중심으로 바꿨습니다. 이탈리안 식당의 줄무늬 차양, 아치 창문과 목재 요리 테이블을 개별 CSS·SVG 요소로 표현합니다. 피자와 도구 역시 독립 SVG이며 한 장의 클릭 그림이 아닙니다.

| 단계 | 조작과 완료 조건 |
|---|---|
| 반죽 | 작은 반죽 덩어리로 시작. 밀대를 드래그해 가져온 뒤 가로·세로를 섞어 총 6번 밀기. 같은 방향의 연속 포인터 이벤트는 여러 번으로 세지 않으며, 가로·세로 동작을 모두 해야 완료. 매번 반죽이 넓어짐 |
| 소스 | 토마토 소스 또는 크림소스 선택. 숟가락을 가져와 터치하거나 문질러 넓은 부분을 여러 번 바르기. 넉넉한 판정의 12개 구역 중 8개를 바르면 남은 작은 빈틈은 보정 |
| 토핑 | 기존 6종과 양파 추가. 터치·드래그·키보드 배치, 마지막 토핑 되돌리기. 토마토·페퍼로니는 46에서 62 SVG 단위로 크게 표시. 음식 안의 재료 SVG가 카드 아이콘 크기에 제한되던 부분도 분리 |
| 오븐 | 왼쪽 피자와 오른쪽 오븐. 오븐 문을 누르기 → 피자를 오븐으로 드래그 → 문 닫기. 3초 동안 불빛·불꽃 표현 후 자동으로 자르기 단계 진입 |
| 자르기 | 피자 칼을 가져와 1~8번 방사형 점선을 터치. 같은 선은 중복 집계하지 않음. 모두 자른 뒤 8개 조각을 실제로 살짝 벌려 표시하고 축하 효과 |

반죽의 ‘6번’은 가로·세로 합계 6번으로 정리했습니다. 한 방향만 반복해서는 완료되지 않습니다. 시간 제한이나 실패는 없습니다.

## 접근성과 작은 화면

도구를 누른 뒤 요리판을 누르는 가져오기 방식도 제공합니다. 휴대폰에서 화면 밖으로 도구를 길게 끌어야 하는 문제를 피하기 위한 대안입니다. 이 방식으로 가져온 뒤에도 반죽을 밀거나 소스를 바르고 선을 자르는 동작은 필요합니다. 키보드는 도구 선택 후 요리판 Enter, 자르기 선 버튼으로 조작할 수 있습니다. 동작 줄이기 설정을 따릅니다.

1280×800·1280×720 태블릿 가로에서는 약 70:30 화면과 하단 버튼을 한 화면에 배치합니다. 휴대폰 가로·세로는 스크롤을 허용하고 가로 넘침을 막습니다. 실제 갤럭시 기기의 손가락 드래그·스피커 확인은 별도로 필요합니다.

## 저장·소리

피자 revision을 2로 올렸습니다. 이전 revision 1 기록은 보존하고 새 플레이를 별도 저장합니다. 반죽 횟수·소스 구역·토핑·오븐 종료 시각·자르기 선을 복원합니다. 굽는 중 재접속해도 남은 시간을 기다리거나 이미 지난 경우 자르기로 이동합니다. 저장이 차단되어도 현재 화면에서는 플레이합니다. 최초 온라인 저장 이후 오프라인 실행을 지원합니다.

상단 소리 설정을 공유하는 SoundContext를 추가했습니다. 기기의 Web Audio로 짧은 ‘띵’ 소리를 합성하며 외부 음원·요청은 없습니다. 완료 직전에 음소거를 켜도 소리를 내지 않습니다. 오디오를 제공하지 않는 브라우저에서는 무음으로 계속 플레이합니다. 실제 스피커 음량은 기기 설정을 따릅니다.

## 코드 분리

- `src/games/cooking/pizza/PizzaWorkshop.tsx`: 직접 조작과 식당 화면
- `pizza/usePizzaWorkshop.ts`, `pizza/types.ts`: 피자 전용 진행·저장 검증·영역 정보
- `pizza/PizzaPanel.tsx`, `components/ToolArt.tsx`: 도구와 소스 선택
- `pizza/useOvenChime.ts`, `src/games/GameSettings.tsx`: 완료음과 공통 소리 설정
- `components/FoodScene.tsx`, `IngredientArt.tsx`: 점진적 반죽·부분 소스·오븐·8조각·재료
- `data/pizza.ts`: 피자 revision 2 및 7종 토핑

요리 선택, 공통 단계 표시와 완료 UI, 다른 세 요리의 확장 데이터 구조는 유지합니다. 기존 공통 CookingGameLayout과 useCooking은 미래 요리를 위한 기본 틀로 남기고, 피자의 고유 동작은 pizza 폴더로 분리했습니다. 색칠놀이 구현과 저장 데이터, 기존 kids-color-by-number 저장소는 변경하지 않습니다.

## 캡처와 검증

`dough-start.png`, `dough-rolled.png`, `sauce-partial.png`, `toppings-cream.png`, `oven-baking.png`, `cutting-guides.png`, `complete-eight-slices.png`는 실제 플레이에서 캡처했습니다. `pizza-*.png`는 태블릿·휴대폰 화면입니다.

검증은 실제 도구 드래그, 방향별 반죽 횟수, 부분 소스와 도구 조건, 두 소스, 양파·토핑 크기, 오븐 순서, 자동 자르기 진입, 8개 선 중복 방지, 완료음 생성·음소거, 오프라인 복구, 구버전 기록 보존, 키보드·저장 차단 및 기존 색칠놀이를 포함합니다.

작업 브랜치: `feat/pizza-touch-workshop`. PR로 검토하고 자동 병합·배포하지 않습니다.

최종 검증 기록: TypeScript·Vite·Pages 검사와 전체 브라우저 검사 53개 통과. 점선 중간 터치 판정을 추가한 뒤 실제 피자 전체 플레이를 재검증했습니다.
