# 통합 홈: 같은 크기의 게임 카드와 가로 스크롤

기존 다섯 게임을 모두 같은 크기의 정식 카드로 표시합니다. 작은 ‘새 게임’·‘준비 중’ 임시 카드는 제거했습니다. 하늘색 배경, 어린이 캐릭터, 큰 제목, 게임별 색상과 일러스트는 유지합니다.

## 화면과 조작

- 1280px 태블릿 가로 화면에는 동일한 카드 다섯 개가 나란히 보입니다.
- 여섯 번째 이후 게임은 카드 크기를 줄이지 않고 오른쪽으로 이어집니다. 12개·13개 목록으로 같은 크기가 유지되는지 확인했습니다.
- 작은 태블릿은 약 네 개, 세로 스마트폰은 큰 카드 한 개와 다음 카드 일부가 보여 가로로 넘길 수 있음을 알 수 있습니다.
- 가로 스크롤이 생기면 ‘이전 게임 보기 / 다음 게임 보기’ 큰 버튼도 표시합니다. 안드로이드에서 스크롤바가 숨겨져도 모든 게임에 접근할 수 있습니다.
- 손가락은 브라우저의 기본 가로 스크롤과 관성 이동을 사용합니다. 마우스는 좌우 드래그와 이동 버튼을 지원합니다.
- 움직임이 있는 누르기와 취소된 터치 뒤의 클릭은 실행하지 않습니다. 새로 누르면 정상 실행하며, 키보드 Enter/Space 선택은 유지합니다.
- 목록에 키보드 초점을 두고 좌우 화살표, Home/End로 이동할 수 있습니다. Tab으로 개별 카드에 이동하면 브라우저가 해당 카드를 보여줍니다.
- 움직임 줄이기 설정에서는 자동 스크롤 애니메이션을 생략합니다.

## 변경한 파일

| 파일 | 역할 |
|---|---|
| `src/components/GameCarousel.tsx` | 등록 목록으로 카드 생성, 스크롤 이동 버튼, 크기/스크롤 감지, 드래그와 클릭 구분 |
| `src/components/game-carousel.css` | 동일 크기 카드, 화면별 보이는 개수, 스크롤과 짧은 가로 화면 배치. 홈에만 적용 |
| `src/main.tsx` | 게임별 예외와 임시 카드를 제거하고 `games` 목록 전체를 새 컴포넌트에 전달 |
| `tests/home-carousel.spec.ts` | 실제 다섯 게임 진입, 동일 크기·화면 크기 6종·실제 터치·마우스 드래그·오작동 방지·저장값 보존·13개 확장 검사 |
| `tests/fixtures/home-carousel.tsx` | 실제 홈 컴포넌트에 확장된 등록 목록을 전달하는 검사 전용 화면. 앱 빌드에는 포함하지 않음 |
| `tests/home.spec.ts` | 임시 카드 제거에 맞춘 홈 검사와 새 캡처 경로 |
| `README.md`, 이 폴더 | 설명과 화면 캡처 |

새 게임을 기존 게임 등록 목록에 추가하면 같은 카드가 자동 생성됩니다. 홈에서는 게임 ID별로 카드 크기나 위치를 따로 지정하지 않습니다. 등록에 필요한 게임 본체·제목·색상·그림은 각 게임 개발 때 준비하면 됩니다. 카드 개수가 많아져도 홈 레이아웃 코드를 변경할 필요가 없습니다.

## 검증

- TypeScript 타입 검사, 프로덕션 빌드, GitHub Pages 배포 파일/경로 검사: 통과.
- 로컬 홈 검사 19개: 통과. 기존 홈 검사 7개와 새 검사 12개입니다.
- 전체 검사 구성은 기존 172개 + 새 홈 검사 12개 = 184개이며, PR의 GitHub 검사에서 전체 회귀 검사를 실행합니다.
- 화면 크기: 1280×800, 1280×720, 960×600, 360×800, 320×640, 800×360.
- 카드 너비·높이·상단 위치가 같고 최소 너비 180px / 최소 높이 175px 이상인지 검사했습니다. 가로 이동 버튼은 52×48px 이상입니다.
- 페이지 전체가 가로로 넘치지 않고, 짧은 스마트폰 가로 화면에서도 이동 버튼이 보이는지 검사했습니다.
- 터치 스와이프 후 게임 미실행과 다음 터치 정상 선택, 마우스 드래그 후 미실행과 마우스 버튼 해제 후 정지, 취소된 터치의 뒤늦은 클릭 차단을 검사했습니다.
- 12개 목록의 카드 크기 유지, 13번째 등록 즉시 표시, 마지막 카드까지 이동·선택을 검사했습니다.
- 다섯 실제 게임 모두 홈에서 열고 돌아오는 동작을 확인했습니다. 홈 스크롤·화면 회전·이동 버튼이 기존 저장값을 수정하지 않는지도 검사했습니다.

기존 다섯 게임 본체, 그림 에셋, 저장 키·저장 처리, 게임 등록 데이터, 공통 소리 설정, PWA와 배포 설정은 수정하지 않았습니다. 실제 갤럭시탭·스마트폰 실물의 터치감은 미검증이며 Chrome의 터치 지원 화면 크기로 확인했습니다.
