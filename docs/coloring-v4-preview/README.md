검토 시 굵고 진한 선의 주제가 색칠 대상, 옅은 선과 색의 주변 풍경이 고정 배경입니다. 완성 미리보기이므로 현재는 주제도 색칠되어 있습니다. 게임 시작 시에는 주제만 흰색과 숫자로, 배경은 이미 칠해진 상태로 보이게 할 예정입니다.

승인 후 개발할 때 배경과 색칠 대상을 별도 레이어로 분리하고, 배경에는 번호·터치·진행률을 적용하지 않습니다. 공룡의 두 나무는 배경과 달리 색칠 대상에 포함합니다. 기존 그림체와 주요 구조를 유지하며 고정 배경은 주제를 가리지 않도록 낮은 대비로 표현했습니다.

사용자 확인 후: 공통 가로 화면 비율 정리 → 배경/대상 분리 → 실제 색칠 영역 생성 → 번호·힌트·완성 PNG 검증 순서로 진행합니다. 사용자 확인 전에는 해당 개발 작업을 시작하지 않습니다.
