# 갤럭시탭 설치와 오프라인 실행

이번 수정 PR을 병합하고 수동 배포한 뒤 진행하세요. 무료 웹앱 설치이며 Play 스토어를 사용하지 않습니다.

## 1. 최신 버전 열기

1. 갤럭시탭의 Wi-Fi를 켭니다.
2. **Chrome**을 엽니다. 카카오톡 등의 앱 안 브라우저 대신 Chrome을 사용하세요.
3. https://leedb333.github.io/kids-game-playground/ 를 엽니다.
4. 네 게임을 한 번씩 열어 정상 화면이 나타나는지 확인하고 홈으로 돌아옵니다. 벽돌깨기는 더 작아진 무지개 패들이 보이면 이번 수정 버전입니다.

## 2. 설치

1. Chrome 주소창 오른쪽 **점 세 개(⋮)**를 누릅니다.
2. **설치 및 바로가기 만들기 → 설치**를 선택합니다.
3. 표시된 설치 안내를 완료합니다. Chrome 버전에 따라 **홈 화면에 추가 → 설치** 또는 **앱 설치**로 표시될 수 있습니다.
4. 홈 화면 또는 앱 목록의 **게임 놀이터 / 어린이 게임 놀이터** 아이콘을 엽니다.
5. Wi-Fi를 켠 상태에서 잠시 기다리고, 네 게임을 한 번씩 열어 봅니다.

메뉴 경로는 [Google Chrome 공식 안내](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ko)를 기준으로 확인했습니다.

## 3. 오프라인 확인

1. 앱을 닫습니다.
2. 갤럭시탭 상단을 내려 **비행기 모드**를 켭니다. **Wi-Fi도 꺼져 있는지** 확인합니다.
3. 설치한 **게임 놀이터** 아이콘으로 다시 실행합니다.
4. 홈 화면과 네 게임이 열리면 오프라인 준비가 완료된 것입니다.
5. 이후에는 같은 아이콘으로 인터넷 없이 실행할 수 있습니다.

앱은 최초 온라인 방문 시 게임 화면·그림·실행 파일을 기기에 저장합니다. 빌드의 모든 게임 파일과 색칠 그림이 함께 저장되는 구조를 확인했고, 자동 검증에서도 인터넷을 끈 새 브라우저 창에서 네 게임이 열리는지 검사합니다. 실제 갤럭시탭 설치와 기기 오프라인 동작은 사용자가 위 순서로 최종 확인해야 합니다.

## 화면이 안 열리거나 이전 버전이 보이면

- Wi-Fi를 켜고 Chrome에서 위 주소를 다시 열어 각 게임이 나타날 때까지 기다립니다.
- Chrome의 이 앱 관련 탭과 설치한 앱 창을 모두 닫고 다시 실행합니다. 새 버전 적용에는 창을 닫았다 여는 과정이 필요할 수 있습니다.
- 다시 비행기 모드에서 실행해 봅니다.
- 앞으로 업데이트를 받으려면 가끔 Wi-Fi가 켜진 상태로 앱을 열어 주세요.

진행 기록과 오프라인 파일은 해당 기기/Chrome에 저장됩니다. Chrome의 사이트 데이터 삭제는 진행 기록과 다운로드된 파일도 지울 수 있습니다.
