# 벽돌깨기 마지막 난이도 조정

- 패들 넓이와 두께를 각각 기존의 2/3로 줄였습니다. 표시와 충돌 크기를 함께 변경하고 무지개 광택도 같은 비율로 줄였습니다.
- 각 스테이지에서 실제로 공이 움직인 시간 약 10초 후 한 번만 1.2배 빨라집니다.
- 준비/공 다시 보내기 대기/일시정지/단계 선택 시간은 제외합니다. 공을 놓쳐도 누적 플레이 시간과 빨라진 속도는 유지합니다.
- 화면 회전이나 크기 변경에도 해당 스테이지의 시간과 속도 증가 여부를 유지합니다. 기기 크기에 맞춘 기본 속도에 1.2배를 적용합니다.
- 다른 단계로 이동하거나 홈을 나갔다 다시 입장하면 그 플레이의 시간은 0초부터 시작합니다. 기존 벽돌 진행/완료 기록 저장 방식은 그대로입니다.
- 대칭 반사, 황금벽돌 즉시 완료, 10단계 구성, 다른 게임과 배포 설정은 유지합니다.

## 검증 및 화면

태블릿과 휴대폰의 가로/세로 화면, 축소된 패들 양끝의 충돌/대칭 반사, 10초 전후의 속력과 방향 보존, 중복 증가 방지, 일시정지/공 놓침/크기 변경/새 단계, 10단계 완료를 검사합니다. 브라우저에서도 실제 플레이 10초 후 속도 변화를 확인합니다.
