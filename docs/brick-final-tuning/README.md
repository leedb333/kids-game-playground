# 벽돌깨기 마지막 난이도 조정

- 패들 넓이와 두께를 각각 기존의 2/3로 줄였습니다. 표시와 충돌 크기를 함께 변경하고 무지개 광택도 같은 비율로 줄였습니다.
- 기본 속도를 처음부터 기존 대비 1.2배로 적용합니다. 약 10초 플레이 후에는 속도 증가 대신 공이 하나 추가됩니다.
- 준비/공 다시 보내기 대기/일시정지/단계 선택 시간은 제외합니다. 공을 놓쳐도 누적 플레이 시간과 두 공 모드를 유지합니다. 한 공이 남으면 계속 플레이하고, 모두 놓쳤을 때만 다시 공을 보냅니다.
- 화면 회전이나 크기 변경에도 해당 스테이지의 시간과 두 공 모드, 남은 공 개수를 유지합니다. 기기 크기에 맞춘 기본 속도에 처음부터 1.2배를 적용합니다.
- 다른 단계로 이동하거나 홈을 나갔다 다시 입장하면 그 플레이의 시간은 0초부터 시작합니다. 기존 벽돌 진행/완료 기록 저장 방식은 그대로입니다.
- 대칭 반사, 황금벽돌 즉시 완료, 10단계 구성, 다른 게임과 배포 설정은 유지합니다.

## 검증 및 화면

태블릿과 휴대폰의 가로/세로 화면, 축소된 패들 양끝의 충돌/대칭 반사, 10초 전후 속도 유지와 공 추가, 공이 세 개 이상 생기지 않는지, 일시정지/공 놓침/크기 변경/새 단계, 10단계 완료를 검사합니다. 브라우저에서도 실제 플레이 10초 후 두 공으로 진행되는지 확인합니다. [두 공 화면과 상세 검증](../brick-two-balls/README.md)
