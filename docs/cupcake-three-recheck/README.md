# 컵케이크 신규 9종 재검수 결과

## 결론: 1종 통과, 8종 보류

신규 원본 9장을 모두 확보·검사했습니다. **빈 3구 트레이 1장만 게임용 통과**입니다. 이전 PR #27의 재료 카드 4장과 합쳐 현재 최종 PNG는 **5장/목표 13장**입니다. 새로 제작됐다는 이유로 컵·볼·재료 레이어를 자동 승인하지 않았습니다. 정식 3개 동시 제작·자연스러운 굽기를 완성할 준비는 아직 부족합니다.

이번에는 단순 크기 비교 외에 기존 종이컵 앞면 추출, 기존 볼 외형 재사용, 재료 축소·재배치·마스킹, 누적 합성, 트레이 3개 배치를 시험했습니다. 숫자상 일부 픽셀을 보존했더라도 눈에 보이는 이음새가 남으면 보류했습니다. 새 원화를 생성하거나 기존 원본을 덮어쓰지 않았습니다.

### 공통 종이컵 앞면 추출 시험

원본 완성 컵의 분홍 앞면을 열별 색 경계로 추출하여 새 3상태에 동일하게 덮었습니다. 알파>250인 앞면 299,754픽셀은 세 시험본 모두 원본과 다른 픽셀 **0**입니다. 하지만 경계 검출이 곡선 테두리·흰 하이라이트를 완벽히 분리하지 못해 연결부가 톱니 모양이고, 새 컵의 뒤쪽/측면이 남습니다. `B` 하단은 이 **불합격 시험본**입니다. 부분 픽셀 0차이를 전체 컵 정렬 통과라고 부르지 않습니다.

**필요한 보완 자료:** 기존 완성 컵과 동일 좌표의 `cup-wrapper-front.png`(흰 물결 테두리 포함), 빈 컵 뒤쪽/안쪽 레이어, 종이컵 없는 `cup-content-batter.png`·`cup-content-half.png`. 기존 완성 컵의 종이컵 외곽/하트/주름/색/바닥은 그대로 두고 내용물만 편집한 3상태 세트도 가능합니다. 1254² 공통 캔버스를 유지하고 상태마다 자동 중앙 정렬하지 않아야 합니다. 케이크에 가려진 컵 안쪽은 원본만으로 손상 없이 복원할 수 없습니다.

## 믹싱볼과 재료 검수

`C0-input-bowl-composites.png`는 제공 빈 볼과 재료를 원래 좌표로 겹친 결과입니다. 네 표면 모두 앞 테두리와 장식을 덮습니다.

기존 `mixing-bowl-batter.png`에서 바깥 형태·하트·받침은 유지하고, 내부 타원 중심 `(622,478)`, 반경 `(518,181)` 안만 새 빈 볼의 안쪽 질감으로 교체하는 시험을 했습니다. 보호 타원 바깥 1,272,065픽셀은 변경 **0**이지만, 반죽 흔적과 다른 볼 내벽의 연결선이 남아 빈 볼로 승인하지 않았습니다. `G-detail.png` 아래 오른쪽이 실패 부분입니다.

재료는 다음처럼 비율을 유지해 축소·이동하고, 더 작은 내부 타원 `(622,478), 반경(502,163)`으로 잘라 앞 테두리 밖으로 나오지 않게 했습니다.

| 재료 | 중심 x,y | 균일 배율 |
|---|---|---:|
| 달걀 | 415,465 | .32 |
| 우유 | 790,460 | .28 |
| 밀가루 | 540,530 | .27 |

`C-bowl-composites-trial.png` 위쪽은 개별, 아래쪽은 기존 재료를 지우지 않고 순서대로 추가한 시험입니다. 가림·누적 자체는 가능하지만 각 재료에 반죽 바탕이 포함되어 작은 원판 여러 개처럼 보입니다. 따라서 단순히 테두리를 가리지 않는다는 이유로 시각 품질을 통과시키지 않았습니다. 이 좌표는 **실패한 실험값**이며 게임 권장값이 아닙니다.

**필요한 보완 자료:** 기존 볼과 같은 외형·위치의 진짜 빈 볼(또는 정확한 볼 앞면/뒤쪽/내부 분리 세트), 반죽 바탕 없는 노른자·흰자/흰 우유/밀가루/설탕 독립 레이어. 현재 4장은 고정 순서의 '반죽 표면 상태'로 쓰는 다른 설계에는 활용 가능하나, 독립 재료를 자유롭게 추가하는 요청과 같다고 볼 수 없어 보류했습니다.

## 트레이 고정 배치

트레이만 통과했습니다. 1800×1000 좌표에서 컵 원본의 발밑 앵커 `(623,1082)`를 아래 위치에 둡니다. 원본 이미지 전체에 균일 배율 `.45`를 적용하며 종이컵을 찌그러뜨리지 않습니다.

| 자리 | 트레이 안 발밑 x,y | 기존 완성 컵 실제 가로 범위(약) |

| 1 | 393,680 | 174.75~611.25 |

기존 완성 컵 본체 사이 여유는 약 72.5px/65.5px이며 가로 겹침이 없습니다. 새 컵 후보들로도 `D`/`E` 배치를 확인했으나 컵 자체 승인과 구분합니다. 프레임 앞쪽 보호 영역은 트레이 y=690 이후 원본을 마지막에 다시 올렸습니다. 현재 컵 발밑 y=680에서는 그 보호선 아래로 침범하지 않습니다. 이는 전용 곡선 앞면 마스크가 완성됐다는 뜻이 아닙니다. 컵 크기/위치를 변경하거나 더 깊게 삽입하는 애니메이션에는 별도 가림 마스크를 재검증해야 합니다.

`D-tray-cupcake-cup-empty.png`, `E-tray-cupcake-cup-filled.png`, `F-tray-cupcake-baked-base.png`를 직접 확인했습니다. 트레이는 사용 가능하지만 D/E에서 사용한 새 컵 파일이 통과한 것은 아닙니다.

## 가공·검사와 기존 게임 보호

- PNG 실제 시그니처/색 유형/해상도/투명·반투명 픽셀/알파>32의 외곽 잘림을 검사했습니다. 최종 트레이의 경계 잘림 픽셀은 0입니다.
- 불필요한 배경 점은 알파 연결 성분의 가장 큰 피사체를 유지하고 2px 주변부와 원래 반투명 가장자리를 보존하는 방식으로 정리했습니다. 그림 전체를 검정색 기준으로 누끼 따지 않았습니다. 제공 재료 4종은 독립 물방울이 아닌 하나의 큰 표면이므로 작은 외부 점을 제외했습니다.
- 입력 9개와 기존 원본 9개·공식 시안 3개의 SHA-256을 전후 확인했습니다. 원본은 변경하지 않았습니다. 카드 4종은 PR #27의 그대로입니다.
- 트레이 비율은 1683:935=1800:1000입니다. 전체 비율을 유지했고 외곽을 자르지 않았습니다. 밝은 체크 바탕에서 주된 원화 스타일·하이라이트·빈 자리와 시점을 직접 비교했습니다.
- `audit.json`에 입력 해시, 가공 크기, 투명 픽셀 수, 제거량, 비교 영역/수치, 트레이 좌표/간격, 상태별 승인 여부를 기록했습니다.
- 신규 게임 코드, 기존 게임 본체, 저장 데이터·저장 키, 홈, 배포 설정은 변경하지 않았습니다. 에셋 전용 검사와 타입 검사를 실행했습니다. 기존 게임 전체 회귀/실제 갤럭시 플레이는 이번에 새로 검증하지 않았습니다.
