# 최신 피자 조작 안내

이 문서는 첫 버전 기록입니다. 현재 도구를 직접 사용하는 버전은 [피자 터치·드래그 안내](../cooking-touch/README.md)를 참고하세요.

# 요리놀이 · 피자 만들기

## 이번 버전

통합 홈의 요리놀이 카드에서 요리 선택 화면으로 진입합니다. 피자만 플레이할 수 있고 스파게티·샌드위치·꼬치구이는 준비 중입니다. 화면은 따뜻한 파스텔 주방과 개별 SVG 음식·재료, 실제 HTML 버튼으로 구성했습니다. 전체 시안을 한 장의 클릭 이미지로 사용하지 않습니다.

피자는 반죽 준비 → 소스 바르기 → 토핑 올리기 → 오븐에 굽기 → 완성 보기의 5단계입니다. 각 단계는 큰 요리 공간이나 도구 버튼으로 조작합니다. 소스는 큰 버튼 한 번으로 넓게 바릅니다. 토핑은 선택 후 누르기, 끌어 놓기, 키보드 Enter로 올릴 수 있습니다. 원 밖에 놓으면 가까운 안쪽으로 보정합니다. 토핑 없이 치즈 없는 피자를 만들어도 실패하지 않습니다. 토핑은 90개까지이며 마지막 토핑을 되돌릴 수 있습니다. 이전 단계로 돌아가 수정하면 다시 구울 수 있습니다.

오븐은 약 4.5초 후 자동 완료되고, 완성 화면에서 만든 피자와 축하 효과를 봅니다. 다시 만들기는 확인 창을 거칩니다. 애니메이션 줄이기 설정을 따릅니다. 공통 소리 토글은 유지하며 이번 버전에는 별도 효과음·배경음은 넣지 않았습니다.

## 공통 구조

- `types.ts`: Recipe, CookingStep, Ingredient, CookingState 계약
- `data/*.ts`: 요리마다 독립된 단계·재료·도구·완료 문구·연출 시간
- `CookingHome.tsx`: 등록된 네 요리 카드와 준비 중 상태
- `CookingGameLayout.tsx`: 공통 주방 배치, 터치 좌표, 앞뒤 이동, 초기화 확인
- `components/StepProgress.tsx`, `IngredientPanel.tsx`, `Completion.tsx`: 공통 순서·재료와 도구·완료 화면
- `components/FoodScene.tsx`, `IngredientArt.tsx`: 음식과 재료의 독립 벡터 표현
- `hooks/useCooking.ts`: 단계별 진행, 토핑 상태, 요리별 자동 저장·검증·복원·초기화

진행은 단계 ID로 저장합니다. 단계 동작은 prepare/spread/place/heat/finish로 분리합니다. 피자의 그림과 위치 규칙은 요리 화면에 분리되어 있으며, 새 요리의 음식 표현·재료 쌓기·젓기 등 고유 조작은 별도 렌더러와 동작으로 추가할 수 있습니다. 다른 요리까지 구현 완료된 범용 게임 엔진이라는 의미는 아닙니다.

저장 키는 `kids-game-playground:v1:game:cooking:<recipeId>:r<revision>`입니다. 색칠놀이 저장 공간은 읽거나 수정하지 않습니다. 저장 불가 시 현재 세션에서 계속 플레이합니다. 굽기 종료 시각을 저장하므로 굽는 중 창을 나갔다 돌아와도 마무리됩니다. 최초 온라인 저장이 끝나면 공통 서비스 워커가 새 요리 코드도 저장해 오프라인에서 실행합니다.

## 이후 요리 추가

1. 해당 요리 데이터 파일의 재료·도구·단계·완료 내용을 채웁니다.
2. 해당 음식의 벡터 화면과 고유 조작(면 젓기, 재료 층 쌓기, 꼬치에 끼우기)을 분리해 만듭니다. 필요한 상태는 공통 타입을 확장하되 다른 요리의 저장 구조를 보존합니다.
3. 음식 화면 선택에 새 렌더러를 연결하고 `ready: true`로 바꿉니다.
4. 그 요리의 플레이·이전 단계 수정·저장·오프라인·반응형 검증을 추가합니다. 도안이 바뀌면 revision을 올립니다.

PNG 저장은 이번 범위에 포함하지 않았습니다. 음식은 별도 SVG로 렌더링하므로 향후 음식 SVG를 내보내는 기능을 추가할 수 있습니다. 효과음과 나머지 세 요리의 실제 플레이도 미구현입니다.

## 확인 화면

- `recipe-selection.png`: 요리 선택
- `pizza-tablet.png`, `pizza-tablet-16x9.png`: 태블릿 가로
- `pizza-phone.png`, `pizza-small-phone.png`, `pizza-phone-landscape.png`: 휴대폰 반응형
- `pizza-complete-tablet.png`: 실제 플레이 후 완성

브라우저의 1280×800, 1280×720 화면에서 왼쪽 약 70% 요리 공간, 오른쪽 약 30% 패널과 화면 내 하단 버튼을 검증합니다. 휴대폰은 요리 공간 아래에 재료 패널을 배치해 세로 스크롤로 사용합니다. 실제 삼성 갤럭시 기기 직접 확인은 별도로 필요합니다.

작업 브랜치 `feat/cooking-pizza`. 자동 병합·자동 배포하지 않습니다. 기존 `kids-color-by-number` 저장소와 색칠놀이 구현은 변경하지 않습니다.

배치 중심·반경과 터치 허용 범위도 요리 데이터의 placementArea로 분리했습니다. 공통 저장·배치 로직에 피자의 위치를 고정하지 않습니다.

검증: TypeScript 검사, 프로덕션 빌드 및 Pages 파일 검사 통과. 기존 홈·색칠놀이 검증 42개 통과, 최종 요리놀이 검증 10개 통과. GitHub에서 전체 52개를 다시 실행합니다.
