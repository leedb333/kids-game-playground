# 컵케이크 화면 품질 보완

대상: `feat/cooking-v2-cupcake-prototype`, 기존 Draft PR [#25](https://github.com/leedb333/kids-game-playground/pull/25). 수정 전 기준 커밋은 `ad5f695`입니다. 병합·배포는 실행하지 않습니다.

## 변경 범위

실제 게임 변경은 `src/games/cooking-v2/cupcake/Scenes.tsx`와 `style.css` 두 파일입니다. 조리 규칙·저장·PNG 좌표·음식 원본·다른 게임은 수정하지 않았습니다.

- 굽기 장면의 높이 기준 크기 상한을 140cqh에서 164cqh로 늘렸습니다. 가로 화면의 실제 오븐은 약 **17.1%** 커집니다.
- 바깥 트레이의 균일 배율은 0.76→0.80, 오븐 안 트레이는 0.43→0.52로 늘렸습니다. 태블릿에서 실제 바깥 트레이는 약 **23.3%**, 안쪽 트레이/컵케이크는 약 **41.6%** 커집니다.
- 오븐을 조금 위로 옮겨 열린 문이 화면 하단에서 잘리지 않게 했습니다. 안쪽 트레이도 오븐 창에 맞춰 재배치했습니다.
- 모든 음식은 기존 PNG와 균일 배율을 사용합니다. 원본 이미지의 가로·세로 비율을 바꾸지 않습니다.
- 폰 세로에서는 화면 폭 98%를 상한으로 두어 좌우 잘림을 방지합니다. 작은 화면에 태블릿 배율을 강제로 적용하지 않습니다.
- 완성 문구 뒤에 크림색 90% 불투명 말풍선·가벼운 테두리·그림자를 넣고 글자를 짙은 갈색으로 조정했습니다. 중복 안내가 겹치지 않도록 완성 화면에서만 정리했습니다.
- 완성 컵케이크와 접시의 위치·크기·구성은 수정 전과 동일합니다. 가로로 짧은 폰에서는 장식 별 줄을 줄여 말풍선이 크림을 가리지 않게 했습니다.

## 검증

추가 테스트 `tests/cupcake-polish.spec.ts`는 실제 터치로 오븐 열기 → 트레이 이동 → 문 닫기 → 굽기 완료까지 진행합니다. 오븐/트레이의 화면 안 배치, 48px 이상 문 버튼, 가로 넘침, 태블릿 확대율, 완성 음식 좌표 유지, 말풍선 중앙 정렬과 크림 가림 방지를 검사합니다.

수정 전 5개 화면 검증과 수정 후 5개 화면 검증을 실행했습니다. 타입·빌드·Pages 경로 검사와 기존 게임을 포함한 전체 자동 테스트 결과는 완료 보고에 기록합니다. 테스트가 다시 생성한 기존 게임 검수 사진은 커밋에 포함하지 않습니다.
