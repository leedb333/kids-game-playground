# 반짝반짝 짝꿍 카드

15단계를 실제로 플레이하는 다섯 번째 게임입니다. 홈의 작은 파랑 ‘새 게임’ 자리를 ‘짝꿍 카드’로 연결했습니다. 기존 네 개의 큰 게임 카드는 유지합니다. 자동 병합·배포는 하지 않습니다.

## 파일과 구조

- `src/games/memory-card/data.ts`: 40개 그림 메타데이터, 15단계 설정, 중복 없는 카드 쌍과 섞기.
- `Artwork.tsx`: 투명 배경의 독립 SVG 그림 40종, 별, 안내 곰. 이모지나 참고 이미지 잘라내기를 사용하지 않습니다.
- `Sky.tsx`: 하늘·무지개·구름·작은 별을 그리는 독립 SVG 배경.
- `model.ts`: 미리보기·선택·비교·힌트·완료 상태와 저장 검증. 화면과 분리하여 자동 검사합니다.
- `index.tsx`: 카드 버튼, 진행 패널, 단계 선택, 일시정지·완료 화면, 소리와 저장 연결.
- `memory-card.css`: 카드의 입체 프레임·3D 뒤집기·축하 효과·화면 크기별 배치. 코디·요리·색칠·벽돌깨기에 적용되지 않도록 범위를 제한했습니다.
- 공통 연결: `src/games/registry.ts`, `src/main.tsx`, `src/Art.tsx`.
- 검사: `tests/memory-model.spec.ts`, `tests/memory.spec.ts`, `tests/memory-visual.spec.ts`, 홈의 준비 중 카드 수만 조정한 `tests/home.spec.ts`.

새 테마는 그림 ID/이름/테마를 데이터에 추가하고 `Artwork.tsx`에 해당 그림을 제작하면 됩니다. 단계는 `stages` 설정에서 짝 수·열 수·테마를 관리합니다.

## 조작과 시간 처리

- 진입·단계 변경·다시하기·이어하기 모두 3초 동안 모든 앞면을 보여주고 입력을 막습니다.
- 서로 다른 두 카드만 비교합니다. 같은 그림은 열린 상태로 남고, 다른 그림은 1초 뒤 닫힙니다.
- 같은 물리적 카드 중복 선택, 이미 맞춘 카드, 비교·힌트 중 추가 입력은 차단합니다.
- 힌트는 아직 맞추지 못한 한 쌍을 2초 보여줍니다. 한 장을 열어 둔 상태에서는 기존 선택을 정리한 뒤 힌트를 시작하며, 힌트로 짝을 자동 획득하지 않습니다.
- 별도 비동기 타이머를 여러 개 만들지 않고, 현재 상태의 남은 시간만 갱신하여 다시하기·힌트·일시정지 충돌을 방지합니다.
- 일시정지·단계 선택 창·다른 창으로 이동했을 때 남은 시간을 유지합니다. 돌아와서 ‘계속하기’를 누르면 재개됩니다.
- 터치·마우스·키보드 Enter/Space와 방향키를 지원합니다. 카드의 공개 상태와 진행률을 접근성 속성으로 제공합니다. 움직임 줄이기 설정을 존중합니다.
- 소리는 앱의 공통 소리 설정을 따릅니다. 일치·완료 때 가벼운 합성음을 사용하며 외부 음원 요청은 없습니다.
- 제한 시간·벌점·광고·계정·추적·외부 링크는 게임 화면에 없습니다.

## 저장과 오프라인

독립 키 `kids-game-playground:v1:game:memory-card:r1`에 마지막 단계, 섞인 카드 위치, 찾은 짝, 완료 단계 목록을 저장합니다. 비교 중인 두 장이나 힌트 타이머 같은 임시 상태는 저장하지 않습니다. 저장 데이터가 손상되면 안전하게 새 판을 만듭니다. 저장 차단 상태에서도 계속 플레이할 수 있습니다.

기존 게임의 저장 키와 코드는 바꾸지 않았습니다. 기존 서비스 워커가 새 게임 파일도 미리 저장하므로 온라인에서 앱 저장이 완료된 후 오프라인으로 진입할 수 있습니다. 브라우저 데이터가 지워진 기기에서는 온라인 연결이 다시 필요합니다. GitHub Pages 경로와 배포 설정은 변경하지 않았습니다.

## 검증 결과와 한계

- TypeScript 타입 검사, Vite 프로덕션 빌드, GitHub Pages 경로/배포 파일 검사: 통과.
- 기존 게임을 포함한 전체 171개 검사: 통과. 이후 무지개 위치를 다듬고 실제 시간 기반 화면 검사를 추가한 최종 카드 게임 22개 검사도 통과했습니다. 기존 150개 + 새 게임 22개로 고유 검사는 총 172개입니다.
- 15개 단계 모두의 3초 미리보기, 정확한 두 장씩의 쌍, 일치/불일치, 중복·추가 입력 차단, 힌트와 일시정지, 모든 단계 완료, 마지막 단계 특별 완료, 새 위치로 다시하기, 저장·이어하기, 저장 차단 복구를 검증했습니다.
- 온라인에서 미리 저장한 앱의 오프라인 첫 게임 진입과 독립 저장 키도 검증했습니다.
- 1280×800, 1280×720, 360×800, 320×640, 800×360의 터치 지원 Chrome에서 카드가 겹치거나 게임판을 벗어나지 않음을 확인했습니다.
- 1280×800에서 8단계 카드는 약 201×202px, 15단계 카드는 약 148×149px입니다. 작은 스마트폰과 가로 스마트폰도 카드 양쪽 길이가 48px 이상인지 자동 검사했습니다. [측정값](card-sizes.json).
- 실제 시간을 사용하는 터치 플레이 검사로 일부 맞춘 카드·한 장을 연 카드·뒷면 카드가 함께 있는 장면을 별도 캡처했습니다.
- 기존 색칠·요리·코디·벽돌깨기 폴더와 배포 설정은 변경하지 않았습니다. 회귀 검사 중 다시 생성된 기존 게임 캡처는 변경에서 제외했습니다.
- 기존 색칠놀이 묶음의 500KB 초과 빌드 안내는 남아 있습니다. 새 카드 게임은 별도 파일로 필요할 때 불러옵니다(약 36.5KB, 압축 약 12.7KB).

실제 삼성 갤럭시탭·갤럭시 스마트폰 실물의 터치감·성능·설치 동작은 미검증입니다. Chrome의 터치 지원 화면 크기 모의 검사이며 실물 검사로 표현하지 않습니다. 20장 단계는 작은 스마트폰에서 카드가 태블릿보다 작습니다. 그림은 직접 제작한 SVG 스타일로, 참고 시안의 세밀한 채색 질감을 그대로 복제하지는 않았습니다.

현재 판은 자동 저장하고 단계별 완료 여부를 기록하지만 모든 단계의 미완료 판을 동시에 보관하지는 않습니다. 다른 단계로 이동하면 이전 단계의 부분 진행은 새 판으로 돌아갑니다.
