# 코디놀이 옷장 목록 이동 개선

태블릿에서 스크롤 막대가 보이지 않고, 옷 그림을 밀면 드래그 착용으로 처리되어 아래 아이템을 찾기 어려웠습니다.

- 옷장에 항상 보이는 48px 이상 크기의 `위로` / `아래로` 버튼을 추가했습니다.
- 버튼을 누르면 목록 높이의 약 80%씩 이동하여 앞뒤 아이템을 겹쳐 볼 수 있습니다.
- 처음과 끝에서는 해당 방향 버튼을 비활성화합니다. 목록 높이가 바뀌어도 상태를 다시 계산합니다.
- 계절·캐릭터·카테고리를 바꾸면 목록을 처음부터 표시합니다.
- 기존 아이템 드래그·터치 착용, 이름 영역 스와이프, 마우스 스크롤, 키보드 탐색은 유지합니다.
- 봄·여름·가을·겨울, 남자아이·여자아이·강아지의 모든 카테고리가 같은 구조를 사용합니다.

## 검증

스크롤 막대를 CSS로 숨긴 환경에서 네 계절 × 세 캐릭터의 모든 카테고리를 검사합니다. 바깥 스크롤이나 `scrollIntoView`로 아이템을 강제로 옮기지 않고, 목록 버튼을 터치하여 모든 아이템 그림이 보이는지 확인하고 각 목록의 마지막 아이템을 터치해 실제 착용·저장 여부를 검사합니다.

태블릿 1280×800/720과 휴대폰 360×800·320×640·800×360 화면을 검증합니다. 실제 삼성 기기는 미검증입니다.

## 변경 범위

- `src/games/dressup/WardrobeBrowser.tsx`: 목록과 터치 이동 버튼
- `src/games/dressup/index.tsx`: 옷장 목록 연결
- `src/games/dressup/dressup.css`: 버튼 크기와 반응형 배치
- `tests/wardrobe-navigation.spec.ts`: 모든 계절·캐릭터·카테고리 및 화면 검증

의상 데이터·착용 앵커·저장 형식과 다른 게임 코드는 변경하지 않았습니다. 별도 브랜치와 PR을 사용하며 자동 병합·배포하지 않습니다.

빌드·TypeScript 검사·GitHub Pages 경로 검증 통과. 신규 목록 이동 테스트 8개 및 기존 코디놀이 회귀 테스트 51개가 모두 통과했습니다.
