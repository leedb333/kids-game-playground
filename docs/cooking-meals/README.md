# 세 가지 요리놀이

기존 피자에 스파게티·샌드위치·꼬치구이를 추가합니다. 자동 병합·배포는 하지 않습니다. 광고·로그인·외부 연결이나 추가 유료 서비스는 없습니다.

## 놀이 방법

- **스파게티**: 면을 냄비로 끌어 넣고 젓가락을 가져와 5번 저어요. 양파와 토마토를 도마로 옮겨 칼로 각각 두 번 자르면 3조각이 돼요. 팬에 세 재료를 넣고 저으면 3초간 볶아요. 토마토/크림소스를 고르고 3번 더 저어요. 파슬리·치즈가루·후추를 자유롭게 뿌려 완성해요.
- **샌드위치**: 1~3개를 고르고 원하는 샌드위치에 재료를 쌓아요. 각 샌드위치에 최대 7개를 넣을 수 있어요. 완성하면 윗빵이 덮여요.
- **꼬치구이**: 1~3개를 고르고 각 꼬치에 최대 5개를 끼워요. 완성을 누르면 꼬치를 화로에 가로로 놓고 3초간 구워요. 다 구워지면 색이 변하고 완성음이 나요. 공통 소리 버튼으로 끌 수 있어요.

재료·도구는 끌어 놓거나, 선택한 뒤 요리판을 터치할 수 있습니다. 젓기는 실제 손가락 이동을 세며, 터치만 반복해서는 진행하지 않습니다. 키보드 사용자는 재료·도구를 선택한 후 요리판 버튼에서 Enter로 놓거나 젓고 자를 수 있습니다. 순서·재료 제한은 실패나 감점으로 이어지지 않습니다. 샌드위치는 내용물 없이도 완성할 수 있고, 꼬치는 전체 중 재료 하나 이상을 끼우면 구울 수 있습니다.

완성 전에는 각 요리 상태가 별도로 저장되어 이어 할 수 있습니다. 완성 후 요리 선택으로 돌아오면 **만들기 시작**으로 표시되며, 다시 열면 새 요리를 시작합니다. 저장 공간이 차단되어도 놀 수 있습니다. 처음 온라인으로 열어 서비스 워커의 저장이 끝난 뒤에는 오프라인으로도 실행됩니다.

## 코드 구조

- `src/games/cooking/data/`: 요리 이름·재료·도구·단계·완성 메시지. 새 세 요리는 revision 2를 사용합니다.
- `src/games/cooking/meal/model.ts`: 상태와 순수 진행 규칙, 입력·저장 데이터 검증. 개수/재료 상한은 요리별로 적용합니다.
- `meal/useMeal.ts`: 요리별 자동 저장·복원·조리 타이머. 키는 `game:cooking:<요리>:r2`이며 앱 저장소 접두어가 붙습니다.
- `meal/MealWorkshop.tsx`: 공통 배치·단계/자유 놀이·터치/마우스/키보드 조작·초기화.
- `meal/MealPanel.tsx`: 재료·도구·소스·개수 선택·마지막 재료 빼기.
- `meal/FoodAssets.tsx`: 양파 단면, 토마토 씨, 채소 잎맥, 새우, 고기 등의 개별 SVG 그림과 조리 도구.
- `meal/MealScene.tsx`: 냄비·도마·팬·접시, 샌드위치 층, 꼬치/화로·구워진 재료 표현.
- `meal/meal.css`: 세 요리에만 적용되는 배경과 반응형 스타일.
- `CookingHome.tsx`: 네 요리 진입과 미완성/완성 상태 안내.

기존 `pizza/`와 `coloring/` 코드는 수정하지 않습니다. 공통 헤더·단계 표시·완성/축하·음소거 효과를 재사용합니다. 배경은 스파게티=기존 피자와 같은 이탈리안 식당, 샌드위치=가정집 주방, 꼬치=캠핑장입니다. 화면 전체를 한 장의 이미지로 덮지 않고 접근 가능한 HTML 버튼과 SVG/CSS 에셋으로 구성했습니다. 외부 에셋 다운로드는 필요 없습니다.

## 검증과 화면

`tests/meals.spec.ts`에서 전체 조리 흐름, 실제 드래그/젓기/자르기, 개별 재료 상한, 되돌리기, 재접속, 완성 후 새 시작, 키보드, 차단된 저장소, 오프라인 굽기 복원, 기존 저장 데이터 보존을 검사합니다. 기존 피자·색칠놀이 검사도 함께 실행합니다.

화면 크기: 1280×800 / 1280×720 태블릿 가로, 360×800 / 320×640 스마트폰 세로, 800×360 스마트폰 가로. 태블릿은 화면 안에 주요 조작 영역을 배치하고, 스마트폰 세로는 요리판 아래로 패널을 배치해 스크롤로 이용합니다. 모든 조작 버튼은 최소 48×48 CSS 픽셀입니다. 브라우저 크기 검증이며 실제 갤럭시 기기 검증은 별도로 필요합니다.
