# 승인 장면 변환

`generate.py`는 승인 원화의 고정 배경 PNG와 독립 색칠 SVG 영역 JSON을 생성합니다. 배경에는 영역 ID를 부여하지 않습니다. 기본 실행은 4개 전부이며 인수 police, fire, dinosaur, butterfly로 하나만 다시 생성할 수 있습니다.

Python 3.12와 requirements.txt의 패키지를 사용합니다. 이전 앱의 도구 폴더가 있으면 읽기 전용으로 재사용하며 bytecode 기록은 비활성화합니다. 출력은 이 저장소 안에만 작성합니다. 원본 시안은 덮어쓰지 않습니다.
